# P1 v0.3：重新纳入规则与结果

2026-10-21｜研究相关性＋记录可用性｜固定 P0：2,707 人

**本版自动保留 2,690 人，17 人待核，未自动排除患者。** P1 提供候选资料池及来源/质量索引，不证明已经发生可纳入的手术决策，也不决定谁才允许进入 P2 探查。P2 的 episode 定义及医生盲评 Reference 均未改动。

## 1. P1 现在回答什么

> 当前交付资料中，是否至少有一条能够回溯、且具有实质研究相关内容的记录？

“相关”围绕本患者 PDAC 的 A（解剖）、B（生物学）、C（患者条件），以及评估或补充证据过程识别。“可用”指可读取并回溯到来源，**不是可以直接作出手术决定**。三个维度不要求同时具备；五血管、尺寸、转移域不要求在同一报告齐备。阳性、阴性、明确无法判断都可以是有内容的记录。

自动纳入不以最终手术、可切除性结局、是否姑息治疗或根治手术标签为条件。仅出现诊断名称，或空白模板标题，不足以证明有实质内容；程序未命中则待核，不直接排除。

这是本次按新原则形成的**操作化第一版**，词表与标题分类尚未经医生独立验证。接近 P0 的纳入人数反映多数患者确有相关资料；不能解释为多数患者已有合格 episode 或完整决策证据。

## 2. 可执行的纳入规则

```text
对固定 P0 中的每位患者，检查全部已交付历史
    # 时间窗只做标记，P1 不预先裁掉更早历史。
    逐份记录定位来源、患者关联、原文与时间字段

    对每份记录分别判断：
        可用性 = 可读取，并能回溯本患者的源记录
        相关性 = 有目标胰腺病变语境
                 AND（A / B / C 至少一项有实质内容
                      OR 有评估、再评估或补充证据的实质表述）
        # ABC 只作非互斥的检索/覆盖索引，不生成临床状态真值。

    若身份索引已核对 AND 至少一条记录同时满足可用性和相关性：
        自动保留候选 INCLUDE_V3
    否则：
        待核 REVIEW_V3，并记录具体原因
        # 全部文件读完后零命中，仍不能证明患者没有相关评估。

    独立保存字段覆盖、来源缺口、引用匹配和差异标记
    不用这些局部标记否决其他已核实记录
```

两条来源路径可以各自支持保留，不要求同时满足：

| 路径 | 本版如何确认可回溯 | 实质内容的例子 |
|---|---|---|
| 原始影像记录 | 当前影像索引文件与冻结输入 SHA-256 一致，并沿用逐来源原文核验结果 | 胰头占位与门静脉关系；明确无法测量；术后目标区域变化 |
| 临床源记录 | 完整 L1 源文件哈希、患者关联、文书类型和物理行可定位；保留逻辑记录 ID 与原文字节哈希 | 目标病变描述、CA19-9 结果、影响耐受的条件、拟完善检查后评估手术等 |

医生相关文书类型由规则识别；护理、同意书等作为补充记录，不单独充当该路径的自动通过依据；未知标题保留供分类复核。没有逻辑记录 ID 但有可定位源文件和物理行时，不直接判为无法回溯。

**影像来源证明本次是复用，不是重新独立核验原始记录簇。** 复用前已确认全部 2,707 份影像索引文件与 v0.2 冻结输入完全一致；临床缓存文件也逐份核对旧输入哈希。若未来原文或来源发生改变，不能继续沿用旧证明。

## 3. 哪些门槛取消，哪些信息保留

| 项目 | v0.3 处理 |
|---|---|
| 五血管逐项齐全 | 取消患者/报告完整性门槛；逐条保留已识别关系及未检出情况 |
| 尺寸、转移模板必须存在 | 取消硬门槛；保存测量对象、时间指向及叙述性表述 |
| 必须增强 CT/MR、必须同时有临床文书 | 不再作为组合患者门槛；实际检查方式和证据来源仍可回溯，后续按用途判断 |
| ABC 全齐 | 不要求；未检出不等于临床明确缺失，更不等于正常 |
| 术后字样 | 上下文线索；不在 P1 重建完整阶段，不自动排除 |
| 多组尺寸、局部阴阳、不同角度 | 保存逐条表述并标记需要上下文解释的差异，不裁决真假 |
| 来源未核验、引用报告未找到 | 局部 mark，保留其他相关记录；不把二手引用伪装成原报告 |
| 读取/解码问题 | 保留覆盖标记；完整性核对失败不得发布“完成全量重跑”的结论 |

本版不生成“某患者受侵/不受侵”的唯一答案，而是保存具体血管、具体原文、时间指向和不同描述。标签用于检索和后续规律探索，不是 P2 起点的 GT。

## 4. 已知解析错误如何避免

| 已确认的问题 | 本版处理 |
|---|---|
| “未见SMA受侵”丢失前置否定 | 保留名称前的局部否定及限定词；增加肯定对照测试 |
| SMA阴性后接肝病变可疑，导致SMA也变不确定 | 按标点和器官对象划分作用域 |
| 脾动脉角度串入SMA | 扩大用于识别对象边界的词表；脾血管被识别不等于成为必需字段 |
| 近段阴性、远段阳性被整体阴性覆盖 | 分段表述各自保存；同片段多种描述不压成单一阴性 |
| 既往和本次同句，整句被丢弃 | 保留两组原文，按局部最近时间提示标记 |
| 正常本次/既往两组尺寸被阻断 | 两组测量分别保留，未设置多尺寸否决 |
| 胆总管直径被当作肿瘤尺寸 | 按测量对象分类；胆管、淋巴结、病理标本不借给肿瘤测量 |
| “转移灶未见明显变化”被识别成阴性 | 区分病变不存在与病变没有变化 |
| 术后早返回遮住其他问题 | 取消报告级早返回，独立收集上下文、来源及内容标记 |
| 同正文的多来源元数据由先读到的记录决定 | 检查名、检查号和来源证明分别汇总，核验状态作确定性的合并；不按首条结果选真值 |

这些修复针对已知反例及其常见变体，不意味着已解决所有中文病历歧义。角度、尺寸仍为带来源的原始表达，不生成病灶级最终量化真值。

## 5. 文书引用原报告的核对

```text
若是拟查、建议、预约的 CT/MRI：记检查计划，不记为缺失报告
若已有检查引用，但没有日期或检查号等具体线索：引用待核
若有检查号：同患者、同模态核对，必要时同时核对引用日期
若只有明确日期：同患者、同模态查找，只记候选匹配
多个检查组无法区分：多义待核，不擅自选最近一次
有索引候选但原始来源未独立核验：来源待核
交付范围内未找到候选原报告：标“交付中未找到”，不推断未做检查
```

全量生成 224 条明确检查号匹配、15,725 条日期候选匹配、248 条多义匹配、2,052 条来源未核验候选、39,263 条交付中未匹配到、42,918 条线索不足引用、2,882 条未来检查计划。

**这些是程序检索的“引用提及次数”，含重复文书和反复引用，不是独立检查数、缺失报告数或确诊数据错误数。** 日期和检查号本身仍可能被引用解析错，以上分类需要对局部样本复核。只允许把它用作追查线索，不允许由此作患者排除或临床 Reference。

样本可见几类差异：临床术前讨论明确但交付影像仅有胸片/非目标检查；原始影像有明确目标和血管描述但没有临床文书；仅术后报告进入旧待核；影像初步诊断涉及邻近器官或非PDAC鉴别诊断。前几类支持取消组合完整性门槛；最后一类提示目标病变与诊断语境仍须在具体 episode 审阅时核对，不能拿早期影像印象重做已交付 P0。

ABC 自动检索覆盖为 A 2,690人、B 2,466人、C 2,656人；按**全部交付历史、含补充文书**计，可能来自不同时间、不同语境，不能拼成基线状态。未检出B/C不代表检查未做或体能异常，检出也不保证是当前状态。护理、同意书、未知标题等分类标记广泛存在，不能把它们的命中人数当成源数据不合格人数。

## 8. 与 P2、盲评和版本控制的关系

P2 应独立根据文字、文书类型和时间组织候选 episode。受侵等标签只用于检索或探索分层规律；没有某个标签不能证明没有手术评估，P1 待核也不能默认阻止 P2 探查。具体决策点再按方案交由医生盲评，得到 Acceptable Mode Set 等 Reference。P1 标签不能作为医生应接受的预设答案。

新一轮 P2 探查应从本轮覆盖全部 P0 的患者索引读取这些标记，不照搬历史采样器中“仅选旧 PASS”的入口。旧100/300人样本仅是原版本开发材料，不能自动代表新候选资料池。
