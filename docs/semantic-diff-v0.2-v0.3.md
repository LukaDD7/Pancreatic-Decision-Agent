# Semantic diff：四阶段提取 v0.2 → v0.3

这是算法含义的变化；旧实现、contract 和输出保留。当前版本仅做单病例试验，没有将全量候选重新判为合格。

| 方面 | v0.2 | v0.3 | 对研究解释的影响 |
|---|---|---|---|
| 执行顺序 | 先拟手术住院/窗口，再找影像 | 先完整来源时间线，再选发现/分期/计划锚点 | 更早发现和既往治疗不会先被窗口裁掉 |
| 病程范围 | 住院前默认 30 天，同住院文书 | 无固定回看窗口；此前临床资料可跨住院 | 不等于把所有历史文书自动开放；仍按可见性及文书内容筛选 |
| 首次发现 | 窗口内最早相关腹部 CT/MR | 来源核对的最早相关报告/外院报告引用；最早本院扫描只是后备候选 | 区分真实发现、首个可取得报告与治疗后复查 |
| 外院发现 | 候选病史默认不进入早期包 | 经 hash/坐标/日期绑定的原文引用可作为发现锚点 | 能生成更早的回建输入，不冒充外院完整报告 |
| 检查边界 | 首份检查日次日零点前，同日汇集 | 该报告/选定轮次返回后，使用 `<=` | 纳入当前锚点，后续同日结果不会仅因同日而开放 |
| 分期轮次 | 窗口内首次增强日 | 选定增强报告集最后一个事件，可显式选一轮多报告 | 轮次选择及理由审计，不宣称四次必须不同 |
| 拟术式前 | `<` 且目标文书隔离 | 保持 `<` 且目标文书隔离 | 不把被评价的真实计划带入模型 |
| 日期级时间 | 整天区间，早期多按日汇集 | 锚点自身可以纳入；其他同日事件顺序未知不自动纳入 | `<=` 不会把日期误解释为午夜精确时间 |
| create_time | 不作为完成时间后备 | 不参与临床排序/锚点/可见性；时间线不设该列 | 改动建档字段不改变资料包或时间线 |
| 影像时间 | 检查时间代理 | 优先显式报告时间，缺失时须 review 接受代理 | 实际报告字段无效不能退回更早检查时间 |
| 入院文书识别 | 标题白名单 | 标题与正文入院标识联合识别 | 减少非标准模板标题造成的遗漏 |
| 空模板 | 可能与正式记录一起纳入 | 含未填写关键字段的模板单列排除 | 仍保留源记录，不把模板文字当事实 |
| 历史治疗 | 关键词可在旧病史中触发截断 | 显式历史段落受保护，本次计划按章节/外部句定位 | 保留穿刺、化疗、疗效及既往计划 |
| 混合未来内容 | 整篇/前缀待审 | 未核实内容仍待审，支持日期绑定原文片段 | 没有为“完整”而直接放开未来信息 |
| 输出 | 四问资料包+来源审计 | 增加完整时间线、备选逐报告输入、病例 semantic diff | 时间线含后续资料，只供审阅；模型只读包 |
| 验证 | 来源/边界执行核对 | 增加等时刻、长病程、跨住院、历史治疗、字段扰动等检查 | 不把程序通过称为临床金标准 |

病例级 diff 由 CLI 的 `--compare` 生成，患者原文和计数仅保存在本地。除按 source_id 比较新增/移除/正文改变外，也比较 `(kind, body_sha256)` 载荷集合，避免把来源编号或展示字段改变当成新临床信息。

新旧 system prompt 与四个问题保持相同；改变的是输入组织和边界，不是引入 Agent memory 或让模型自主申请检查。

上游代码审查后的补充：同份文书对同一外院检查的现病史和辅助检查引用，可经分别审阅后共同锚定发现事件，保留不连续原文坐标，不携带中间的后来查体。病例 diff 同时保留旧版本的 `checkpoint` 关系和时间，支持 v0.3 输出之间比较。
