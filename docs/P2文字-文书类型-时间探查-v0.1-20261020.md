# P2：先按文字打标签，再看文书类型与时间关系

2026-10-20｜探索方案 v0.1｜不改 P1、不直接认证决策点。

## 工作顺序调整

**先做“判断性文字 → 字面标签 → 文书类型分层 → 时间邻域抽样”，观察规律后再确定决策点定位规则。** 暂不把复杂的当前性、目标对象和 episode 语义判断放在第一步硬筛；这些问题在样本中核查，再转成必要的修正规则。

“拟行胰腺根治术”是找决策的线索：计划在该表述被写入前或同时已存在。但它不保证是最初决策，也不保证最初决策仅发生在前24/48小时；可能入院前已经决定，住院后再次确认。

## 第一版字面标签

| 标签 | 典型表述 | 接下来优先看什么 |
|---|---|---|
| `PLAN_CURATIVE_PANCREAS` | 拟行胰体癌根治术、建议胰腺根治性切除等 | 术前文书之前的首次查房、首次病程、会诊中，是否已有同类计划或选择依据 |
| `INDICATION_YES` | 有手术指征、手术指征明确 | 文字是否位于查房/会诊意见或术前小结；同日及此前有哪些判断记录 |
| `INDICATION_NO` | 无手术指征、不宜行手术治疗等 | 先分清原文是什么，再看写在当时意见还是后来回述中，不立即判定当前不可切除 |
| `PAST_INDICATION_NO` | 考虑当时无手术指征 | 根据病史上下文寻找更早诊疗记录，不能机械套回述文书前48小时 |
| `SURGERY_INTENT_GENERIC` | 拟行手术治疗、择期手术等 | 抽样看手术对象，以及更明确的同一计划出现在哪篇记录 |
| `NAT_INTENT` | 拟行术前新辅助治疗等 | 看与否定手术、治疗前评估文书及后续重评的时间关系 |
| `FITNESS_NO_CONTRAINDICATION` | 无手术禁忌症、排除手术禁忌等 | 作为对照标签，不能误判为“无手术指征”或直接当作切除性结论 |

允许多标签。例如“考虑当时无手术指征，拟行术前新辅助治疗”可同时命中三个标签，不必在召回时就完成临床解释。标签先用于抽样，不能要求只有某一个标签的人才进入最终 P2。

## 已做的小样本探查

使用同一批已冻结的30人、878条文书；原始文件仅部分可读的限制仍适用，不能外推人群比例。

- `PLAN_CURATIVE_PANCREAS`：53篇、18人；其中首次上级查房14篇，术前小结15篇，术前讨论15篇，其他9篇。
- `INDICATION_YES`：4篇、2人；`INDICATION_NO`：14篇、3人；`PAST_INDICATION_NO`：12篇、2人，说明回述会造成重复命中。
- 在术前小结/讨论中取每个患者—visit首个根治计划标签，得到15个锚点、15人。这里的visit仅用于附近记录检索，不等于episode。

按**正文头时钟**查找同患者、同visit的更早文书：

| 配对对象 | 找到配对的锚点数 | 24小时内 | 48小时内 | 间隔中位数 |
|---|---:|---:|---:|---:|
| 最近一篇更早首次病程 | 15/15 | 7/15 | 9/15 | 32.47小时 |
| 最近一篇更早首次上级查房 | 15/15 | 10/15 | 12/15 | 13.08小时 |
| 更早且也命中根治计划的其他文书 | 12/15 | 8/12 | 9/12 | 15.88小时 |

最后一行12份文书在本样本中均为主治医师首次查房记录。另3对超过48小时，其中2对约48.1小时，1对约128.8小时。**因此，优先回找首次查房值得继续验证，48小时暂不适合作为硬截断。**

系统记录时钟也另行计算：最近首次上级查房的间隔中位数变为约0.04小时，更早同类计划约0.18小时。不能据此认定临床判断在几分钟内完成；这种差别提示应保留两套时钟，查看补录/记录方式。上述数值均为文书间隔，不是已验证的“决策到记录延迟”。

已生成每类至多2人的分层样本卡，共14张；各卡保存命中上下文、文书类型、正文头与系统时间、来源键及相关配对，供下一步直接审阅。

## 文书规定怎样帮助定位

国家《病历书写基本规范》（卫医政发〔2010〕11号）规定：首次病程在入院8小时内完成，入院记录在入院24小时内完成，主治医师首次查房记录在入院48小时内完成；常规会诊意见在申请发出后48小时内完成；术前小结、术前讨论在手术前形成。见[国家卫生健康委原文](https://www.nhc.gov.cn/wjw/gfxwj/201002/79d42b9c8b3f47ee91000d31de116784.shtml)。本次未取得本院更细的文书制度，也未验证每份病历实际遵守时限。

这些规定可以指导“优先去哪里找”：术前标签→首次查房/首次病程；会诊标签→会诊申请及会诊意见；历史标签→更早诊疗记录。**时限有各自起算事件，不能统一解释为标签文书之前24/48小时内必有最初决策。**
