# 决策前材料mask：两条原则，试行v0.1

2026-10-23。服务于候选checkpoint的医生盲评和Agent测试。独立于“根治路径关联、决策相关证据演化”的定位规则；不改原始文书、既有A/B/C或医生Reference。当前输出仍为研究JSON/Markdown，不宣称已完成FHIR资源封装。

## 先固定本次要回答的问题和切点

例如“首次外科评估下一步怎样推进”“既有计划后是否进一步确认”“已完成当前探查后下一步怎样处理”。同一份文字对不同问题的输入资格可以不同。定位者/材料制作者能看完整轨迹；接受评价的模型/盲评医生仅接收对应冻结包，不沿用看过目标答案的上下文。

## 原则一：时点可见

保留这次选择形成前已经可获得的临床信息和此前已存在的管理状态。按内容所处阶段和来源证据判断，不只按文书录入时间，也不把文字排列当作可靠临床时钟。

术后文书可明确回述切除前的探查，但只能作为阶段重建，保留其事后记载来源及局限；未认证实际可见时间和完整性。先后或可见性不清的片段标REVIEW，保留在制作者审计中，不静默当作没有证据，也不默认放入正式输入。

## 原则二：当前选择隔离，决策依据保留

保留支持独立判断的病史、检查、观察、条件及真实既往计划；隔离本次实际选择、揭示该选择的综合结论，以及选择后才产生的执行和结局。不能为了隐藏答案连同所依据的解剖/生理事实一起删除。

语义判断相对于当前问题：评价下一步处理时，“无血管侵犯”可作为术者所记观察/评估保留，不能升级为独立病理真值；如果任务本身是抽取/判断血管侵犯，该答案性标签就需另行处理。既往计划对后次复评是合法上下文；同次决定在另一处重复、或是否属于既往尚不清楚，不能仅因写在前面就保留为历史。

例如“未见侵犯，遂决定切除”：前段观察保留，后段当前选择遮蔽。实际术式、后续切除步骤、标本/病理/恢复结局，以及标题、术式模板名、字段、叙述文本中对实际选择的重复，同样核对并遮蔽。

## 一次语义分离调用的最小接口

输入：当前问题和阶段切点、完整原文与来源/版本、必要的既往上下文。它是材料制作者调用，可看当前答案；不是被测决策Agent或盲评医生。

输出只提出逐字区间，不改写病历：

```json
{
  "source_id": "source-id",
  "source_sha256": "hash",
  "start": 0,
  "end": 10,
  "quote": "逐字原文",
  "disposition": "KEEP | MASK | REVIEW",
  "reason": "按时点与当前选择两原则说明"
}
```

程序核验hash、quote、坐标、区间覆盖及相互不重叠，按区间执行；不让模型重写一份看似完整的新state。混合段落须分开标，必要连接不清则REVIEW。另检查标题、元数据、所有重复副本与原文取回入口。一次模型输出先是候选；语义审核分别检查“答案是否残留”和“是否误删决定前证据”。

原文只读；KEEP组成输入视图，MASK与REVIEW保存在制作者审计中。无临床含义的格式行不必呈现。输入使用中性编号，不展示遮蔽原因、目标实际动作或能指向实际术式的名称。尚未解决的REVIEW不能被零标记地当作源文无记录。

同一checkpoint给医生与Agent使用同一冻结临床内容和呈现方式，保存内容hash；任务指令可以按方案分别设置。只给可见视图的读取权限，禁止通过原文链接、FHIR附件、narrative或全量Bundle绕回被遮蔽内容。标准化承载不替代时点和语义隔离。

当前试例为AI语义判定+确定性区间输出及核验；没有声称已建成通用自动mask服务、临床验证或正式FHIR接口。后续先检验这两条原则是否反复遇到无法执行的情形，再决定是否迭代。
