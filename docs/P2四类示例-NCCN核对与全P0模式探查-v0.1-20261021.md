# P2 四类示例：临床含义与可扩展检索模式

版本：p2-four-pattern-probe-v0.1-20261021。性质：规则开发与原文探查，不是正式 episode 划分或临床 Reference 验证。既有 P1、P2 代码和冻结结果未改。

## 1. 结论与依据的边界

原来的 B02、B03、B06、B01 都应保留为**与当前手术路径有关的候选决策记录**。它们分别体现暂缓、先处理再评估、初步推进、转向非手术管理；不能将四类记录一律视作最终手术授权，也不能由记录的存在推定当时判断正确。

本轮检索到 NCCN 专业版 v4.2026 的[文章摘要](https://pubmed.ncbi.nlm.nih.gov/42869082/)，但未能读取该专业版正文。具体路径核对采用可读的、由 NCCN 编写的[2025 患者版](https://pancreatic.org/wp-content/uploads/2025/07/NCCN-2025-pancreatic-patient.pdf)，其第 1 页注明基于专业版 v2.2025。以下不是对 v4.2026 全文的审阅，也不使用新指南追溯判定早年病例对错。

NCCN 将病变范围、身体条件和多学科评估纳入治疗选择；胆道梗阻有相应处理路径；新辅助治疗后需重新评估手术可能性。参见上述患者版印刷页 9–10、28、34–35、49–50。这支持寻找“手术路径上的评估与安排”；指南没有定义本研究的病历决策点，也没有规定统一的 24/48 小时检索窗口。

**本研究暂用的操作性理解：某份文书记录了当次对是否、何时、或以何条件推进胰腺根治切除路径的判断、选择或下一步评估安排。**这是研究定义，不是 NCCN 原文。定位到记录之后，还要判断其目标、语境和时间是否足以成为可评价的 checkpoint。

## 2. 四例分别说明了什么

表中均为分析者概括，不替代源文书。

| 原例 | 当次记录所表达的选择 | 为什么值得定位 | 不能由此推出 |
|---|---|---|---|
| B02：感染暂缓 | 目前身体条件不宜手术，先处理疾病并取得后续检查信息 | 当下已在选择“现在是否推进”，即使解剖上可能切除也有这个问题 | 感染必然构成手术禁忌；已经解剖不可切除；自动属于 HOLD_FOR_EVIDENCE |
| B03：减黄后重评 | 先解除梗阻，再评估外科治疗及其他方案 | 是现在作出的分阶段管理安排，包含一个未来需回答的手术问题 | 每位黄疸患者都需术前减黄；重评已经发生；单独一次 ERCP 就是根治手术决策 |
| B06：转外科手术 | 已有肯定手术机会的判断，建议转外科继续治疗 | 有明确的路径推进意见，可用于找更早评估及后续复核 | 已完成最终手术授权；所有证据缺口均已解决；专家应判 ADVANCE |
| B01：转非手术管理 | 根据所述疾病情况，当前不继续手术路径，拟取病理后系统治疗 | 否定判断也在回答手术路径问题，可成为评估的终点候选 | 判断一定正确；患者从未进入过手术评估；后续永远不能重评 |

这里需保留两项区别：

1. **身体条件优化与补充证据不同。**B02、B03 是否适用方案中的 HOLD_FOR_EVIDENCE，要看是否确有影响路径选择的待解决证据问题；不能见到“等好转”就自动赋予该模式。现行 ADVANCE 也包含术前准备，因此仅靠“先减黄”无法完成模式映射。此处先保留临床安排，最终适配仍需明确 checkpoint 范围并由专家评价。
2. **记录一项判断与构成独立 episode 不同。**B06 可以是评估过程中的一次初步意见；B01 可以是首次明确评估即结束当前手术路径。是否独立成段，不能由正/负标签自动决定。

## 3. 如何从更多样本找同类记录

从四例得到的可检验结构是：**手术路径表述 + 与其相连的理由或条件 + 当前/未来安排的语境**。理由齐备的记录适合作为开发起点；缺少显式理由的“拟行胰十二指肠切除”等记录仍须保留在其他检索规则中，不能被这四类模式排除。

| 模式 | 本轮优先检索的文字共现 | 文书类型提供的线索 | 时间关系应怎样核对 |
|---|---|---|---|
| 条件性暂缓 | 感染/发热/身体条件线索 + 不宜或暂缓手术 | 首次上级查房、其他查房中的病情分析/指示 | 先核对这是新出现的条件、再次确认还是旧经过；后找处理安排和后续重评。患者/家属选择另标来源 |
| 处理后再评估 | 减黄/梗阻/ERCP + 再评估手术或后续手术方案 | 查房、会诊、计划段；也会出现在 ERCP 术前文书 | “再评估”指向未来，不等于发生；寻找后续实际评估记录，不能把引流或新辅助治疗开始时间当成重评时间 |
| 肯定机会并转诊/安排 | 有手术指征/具备条件 + 转外科/建议手术/拟切除 | 首次查房、其他查房、会诊、转入/转出 | 优先核对外科会诊意见及转诊原因，再看术前评估；明确意见可能早于术前讨论超过 48 小时 |
| 当前不推进 | 疾病范围线索 + 无指征/不具备条件/不宜手术 | 分析讨论段、会诊、MDT；也可能被带入后续病史 | 先找当次判断及替代安排，再追所引用证据；不能把以后每次化疗中的旧判断复述都算成新决策 |

“首次上级查房”等是代码归并的**文书类型组**，不是标签，也不是确认决策的充分条件。保留医院原始文书名；“术前”还必须核对所指操作，可能是活检、ERCP、镇痛操作。

四例不支持统一倒推 24/48 小时：B06 最早已观察到的肯定意见与后续术前小结，按正文记录头计算约相隔 79 小时；另外几例的正文与系统时间存在不一致。两套时钟都保留，不擅自选择一套作为临床真实发生或当时可见时间。以上仅为原例观察，不是全队列时间分布。

## 4. 全 P0 运行及样本核对

输入为固定 P0 的 2,707 人，读取 265 份临床缓存，共核对 210,144 行源记录。按文书名称剔除护理、同意书、交接、核查等范围后，143,712 行进入正文检索；没有使用 P1/QC 状态作门槛，没有要求正文必须出现“胰”。本轮扫描全部交付历史，没有研究期过滤；正式 P2 仍须按已约定研究期确定 episode。

本轮采取**窄范围的句内共现规则**：以句号、分号、换行分隔，不跨句拼原因与判断。它用于检验四种模式能否复现，远非所有手术决策的完整词表。

| 文字共现类别 | 原始命中片段数 | 涉及患者数 | 旧程序另标“当次意见”的片段数 / 患者数 |
|---|---:|---:|---:|
| 身体条件线索 + 暂不手术 | 10 | 5 | 5 / 5 |
| 减黄/梗阻线索 + 手术重评/计划 | 6 | 3 | 1 / 1 |
| 肯定手术机会 + 转外科/安排 | 20 | 14 | 8 / 6 |
| 疾病线索 + 不手术表述 | 198 | 23 | 13 / 10 |

各类别可重叠，共 234 个片段，涉及去重后的 44 人。最后一列仅为旧规则提供的复核优先级，**不是确认数，也不能用作 P2 的纳入门槛**。原来的四例均检索到，属于开发样例回找成功，不构成外部准确性验证。其余患者未被这四条窄规则命中，不能据此认为没有决策或资料不可用。

按四类 × “旧程序标当次/未标当次”分层、固定种子 20261021 每层至多抽 6 条，共 40 条开发片段，逐条查看其文字和文书信息。这个抽样会重复涉及同一患者、甚至同一既往事件；本轮不是独立盲评，不能计算决策点的临床敏感度、阳性预测值或每人中位数。

核对得到六项具体认识：

- **新的条件暂缓样本可复现。**除了感染本身，也有感染风险背景下家属决定暂缓。这是路径选择的记录，但必须把医学评估和意愿分开。
- **减黄链可以嵌套新辅助治疗。**新样本写的是既往 MDT 建议先抗肿瘤治疗后再评估，当前需 ERCP 为该治疗创造条件；相似表述又出现在 ERCP 的术前小结、讨论和术后病程中。应区分“早前 MDT 意见”“当次解除梗阻安排”“以后真正重评”，不能把它们当成三次根治手术决定。
- **转科是有价值的定位入口。**样本可见外科评估、手术意愿、转科安排相连；但转入目的可能复述已有意见，需要回找会诊而非一律认定转科日是最初决策日。
- **旧“当次意见”标记存在双向错误。**有当次治疗意见因写在“诊断依据/辅助检查”附近而未被优先标记；也有术前小结中复述数月前不手术经过，被标成当次意见。不能以段落或文书名一票通过/否决，故本轮全部保留待核。
- **同一文书可同时保留早期否定与当前肯定。**新样本中，术前小结先回述治疗前无手术指征，再列治疗后影像和当前具体切除计划。较早的否定句仍有研究价值，但其时间应追溯早前评估，不能覆盖当前计划，也不能算成当日新作出的否定判断。反过来，当前计划的存在不证明早前判断错误或当前选择正确。
- **共现不等于因果。**长段里可同时出现“排除某处转移”和“局部进展、暂无指征”；程序这里只检索到了两类文字，不能认定被排除的转移导致了不手术。B01 邻近相反计划还引用同一影像，不能仅据结论变动便宣称是新证据驱动的更新。

## 5. 下一版规则的逻辑与代码对应

以下区分本轮已运行的检索与尚待定稿的决策点复核。前者已执行，后者没有偷偷写成正式 episode 算法。

```text
对 P0 的每份范围内临床文书：
    找手术判断/安排及其条件线索
        在同一片段配对四类词组；原句与偏移全部保留
        # 先验证能否找到可解释的模式，共现本身不认证因果

    为命中附加语境线索，不据此删除
        标疑问、否定、历史/当次不明、段落及可能操作对象
        # “是否有指征”不是肯定判断；旧段落标签也可能漏掉当前意见

    保存来源与时间
        保留文书原名、患者—就诊键、正文时间、系统时间、源行
        # 就诊键仅帮助找邻文，不是 episode；两套时间都不是已验证的临床时间

对待核命中及其原文邻域，后续复核：
    确认其指向的是胰腺根治切除路径还是其他操作
        同时看判断句、前后文及拟行操作；未明则待核
        # 活检/ERCP 的“术前”不等于根治手术的“术前”

    区分当次判断、当前援引旧意见、单纯历史复述及未来计划
        检查时间措辞、叙事连接和明确意见来源，不只看段落名
        # 一个“目前”也可能被复制进后续病史

    将同一患者的相邻相关文书放在原始来源索引下对照
        同句复现只标重复；新证据/新条件/明确重新评估标更新候选
        # 不按固定小时数或标签变化自动分成独立决策

    判断能否锚定评价时点，并另行确定 episode 归属
        记录仍有争议的时间、来源及意见差异
        # 找到决策记录，不等于已确认可做盲评的独立 checkpoint
```

已执行的代码入口：

| 文件/函数 | 本轮作用 |
|---|---|
| `p2_four_pattern_probe/rules.json` | 四类完整正则、版本；句内共现而非临床条件判定 |
| `probe.py::find_patterns()` | 输出每条命中的原文坐标，不把跨句内容拼成事实 |
| `probe.py::annotate()` | 附加旧 P2 角色提示；无匹配及不优先者仍输出 |
| `probe.py::main()` | 全 P0 源计数/哈希核验、抽样、聚合、原四例回找；不产生 episode |
| `tests/test_probe.py` | 合成对照：四类阳性、仅 ERCP、仅化疗周期、历史、疑问、跨句误配和偏移重放 |

下一步最值得扩展的是“治疗后重新评估 + 当前手术路径选择”，以补充这四类窄检索；单纯化疗周期不能代替重评。与此同时，针对本轮发现的语境错误，用整份原文校准“当前/历史”和“所指操作”，再制定独立 checkpoint 的合并规则。先完成这两件事，才能合理估计每位患者有多少决策点。

盲评阶段，检索时用到的真实治疗选择句不能成为医生或 Agent 的预设答案；材料如何按时点遮蔽、保留证据和处理可见时间，仍按最终盲评方案另行实现。本轮不改原始临床文本，也不生成正式盲评包。

## 6. 版本与复跑

新增独立探索模块，未修改旧 P2 v0.3 定位、24/48 小时压缩代码，未修改 P1、研究方案及患者成员。原因：先检验四类临床模式，避免将旧的类型/段落过滤或固定窗口直接固化为新 P2 规则。此版本是新增探查，不与旧 300 人候选链数作差。

从独立版本库根目录运行：

```bash
/opt/anaconda3/bin/python3.12 -m unittest discover -s scripts/cohort_construction/p2_four_pattern_probe/tests -v
/opt/anaconda3/bin/python3.12 -m unittest discover -s scripts/cohort_construction/p2_decision_localization/tests -v
/opt/anaconda3/bin/python3.12 -m scripts.cohort_construction.p2_four_pattern_probe.probe
```

验证：新增 7 项测试与既有 P2 的 15 项测试通过。数据运行逐文件核验 265 个缓存哈希，逐患者核验源记录计数，并重放全部引文偏移。合成测试保证相应代码行为，不代表临床验证完成。

不含逐人数据的聚合统计为 `docs/p2-four-pattern-probe-v0.1-20261021.json`。原文、患者键、40 条样本及复核笔记位于忽略追踪的 `local_artifacts/p2_four_pattern_probe_20261021/`；输入及依赖哈希见其 `run_manifest.json`。Git 仅追踪代码、合成测试和本报告等聚合材料。
