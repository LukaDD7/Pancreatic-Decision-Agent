# Checkpoint材料独立语义审核与表单冻结草案 v0.2

2026-10-28。本文承接v0.6和FHIR／HTML接口闭环。代码合同升级为 `SemanticAudit 0.2.0`；**这是一份供独立审核者与临床团队执行、修订和冻结的方案草案，不是已经完成的临床方案冻结或医生Reference。**原 `研究方案/v0.2/研究方案-v0.2-manuscript.md` 在当前工作目录未找到，因此不能宣称本文已逐字继承其中Q1–Q5的完整原定义。

## 1. 当前真实材料暴露的具体问题

三个研究者示例共有343段REVIEW，旧合同却只有一个PASS/FAIL/PENDING状态和四个布尔检查项。它不能记录每段如何处置、审核者实际看了哪些来源、何时可作时间边界，或哪些缺口阻止发放。

|对象|原文中直接观察到的情况|本轮处理|
|---|---|---|
|DeepSeek SCALE-01术中对象|`实施手术名称`在“手术经过”之前回述当前实际选择；探查中“打开肝结肠韧带”等操作位于选择子句之前；MASK仅覆盖“遂决定……”|这些均不能以单一MASK提示自动放行。当前重点审核包按探查前／探查后观察、同次实际选择回述、选择后操作分别登记|
|Qwen SCALE-01同一原文对象|整段探查被作为观察引文，包含目标临床决策；该对象的`checkpoint_status=UNCERTAIN_CONTRACT_OR_SOURCE`|制作材料审核不自动把它晋升候选Checkpoint，也不能把研究材料边界修订当作模型状态修复|
|DeepSeek SCALE-04单来源对象|文书没有实际选择日期/时刻；混合术前讨论和术后首次病程标题；前文含多次既往手术安排|保留独立审核未决；不能凭文档顺序生成当时可见性，也不能把`CANDIDATE_FIRST_ANCHOR`当临床已确认起始点|

## 2. 材料审核与临床盲评是两件事

- **独立材料审核者**阅读研究者可见的完整原文、候选分区及覆盖清单，审核当前目标临床决策的边界、跨文书回述、当时可见性和必要资料范围。其结论绑定 `compiled_sha256`。
- **医生盲评者**只阅读审核后、绑定冻结表单的许可包，先评价任务/材料是否可评价，再独立填写临床Reference。医生不能从隐藏脚本、附件、页面源数据或未来Checkpoint获取实际选择。
- 材料审核通过不等于临床建议正确，不等于原模型分类正确，也不等于正式Episode边界已确认。候选材料修订不能覆盖发现/复核LLM输出或改变患者成员。

## 3. 当前审核者逐项填写的最小内容

1. 审核者、审核时间、协议版本和独立性声明。`independent_review_process`只表示一种审核流程身份；程序不证明实际人员独立性。
2. 当前审核实际包含的source ID、显式排除的source ID、范围依据和`COMPLETE/INCOMPLETE`。仅写“全病历已看”不够；清单之外是否仍缺必要资料必须单独判断。
3. 临床决策时间证据：依据、精度、是否知道确切时刻及不确定性。回顾性重建不能冒称医院当时EHR快照；文书13:16记录术中09:00–13:00的操作，不能证明13:00检验在选择前已知。
4. 每一个原文字符区间：来源hash、逐字原文、原处置、`ACCEPT/REVISE/UNRESOLVED`及理由。`REVISE`明确KEEP或MASK，未解决仍REVIEW。
5. 每份来源覆盖结论：已审纳入、已审排除、必要但未交付、交付中未找到或未解决。缺来源不自动排除患者，也不能用局部缺口抹掉其他已核实记录。
6. 具体问题的归因：模型提案、来源处理、材料组装、来源可用性、独立审核未决或其他。源资料存在差异不自动算数据错误。

`ACCEPT`不能用于REVIEW；`PASS`必须同时满足完整审核范围、所有检查真实完成、所有字符有明确评估、无未解决段和无开放阻断问题。FAIL/PENDING可以携带明确修订提案，但仍不能冻结医生包。

## 4. 时间边界和原文处置

|资料|KEEP候选必须有的依据|应MASK或保留REVIEW的情况|
|---|---|---|
|目标选择前的同篇观察|原文明确处在选择之前；选择子句没有混入；具体可见时间或事件顺序可成立|叙述顺序与真实决策时间无法对应；事实与选择连成不可拆的错误提案|
|既往临床安排|属于目标时点前已作出的管理安排，可支持当前任务|当前目标选择的换句话回述；不能因“拟”字就一律保留|
|当前手术记录的头部/栏目|逐字段区分真实术前计划与术后回写的实际实施|实施术式、重建方式、实际切除范围、术后结局；不能整段凭标题放行|
|外部检验/影像/文书|目标时点前已可见的版本与依据，且服务于当前临床问题|只有报告日期、手术分钟未知、同组报告版本可见性未知；不能因“术前”字样自动通过|
|操作/结局|属于当前选择之前、且不是泄漏当前答案的必要观察|选择后切除、重建、病理、术后状态；不能因为DeepSeek的postchoice提案漏掉就保留|

MASK是许可范围不足或需要遮蔽的处置，不等于该段是源数据错误。对同一次术中决策的材料重建，可采用“探查后、切除操作前”的阶段边界，但必须明确这是LLM提议后经审核的事件顺序，不是精确决策分钟。

## 5. 试评表单草案：等待临床团队冻结后才能发放

下列定义来自2026-10-13医生反馈后的方案草案及现有三Mode／20动作研究资产。此处整理为**试评表单提案**，不将旧Agent输出格式自动升级为正式专家方案。临床团队须明确版本、指南适用年代、评审人数、分歧程序、Severity和Confidence锚点后才能冻结。

### 5.1 决策任务与可见资料

- 任务：针对PDAC可切除性／当前根治切除路径，在明确时点及当时许可资料下，评价可接受的管理模式和下一步动作。
- 不把实际手术、最终可切除、姑息治疗或P1 PASS作为进入本题的标准；也不要求资料足够推进手术才可评价。
- 未知、无法判断、原报告未交付和检查计划分别保留。医生不能用后续结局补写当时资料。
- 术中包必须说明选择前阶段边界；若当前包同时存在不可逆操作已开始的文字或实际选择回述，不能按普通术前任务发放。

### 5.2 建议题目

|组|条目|回答要求|
|---|---|---|
|任务与有效性|当前临床问题、拟评价路径及时间边界是否明确|VALID／REPAIR_REQUIRED／UNCERTAIN；问题代码与说明。REPAIR_REQUIRED停止该版本临床评分|
|资料|是否有理由认为当时可见且本应纳入的资料被遗漏|是／否／无法判断；列具体来源或信息，不用未来结果“修好”当前包|
|Q2 Mode|哪些管理模式可接受|多选CONTINUE、PAUSE、EXIT；另有UNCERTAIN，不能把无法判断当作0分|
|路径与动作|每个可接受Mode对应的具体下一步、路径范围、转向和复评条件|多选；每题允许补充列表外动作。候选20动作只是研究分类，不是答案|
|Q3动作评价|针对候选或补充动作，在该时点是否可接受|Yes／No／Uncertain分别保存；动作合理不能代替Mode合理，历史是否存在结果也不能代替此项判断|
|偏好与不合理项|首选下一步及明显不合理模式/动作|首选不限制可接受集合；不合理项须写理由|
|Q4 Severity|对不可接受Mode／动作的潜在严重度|由临床团队另行冻结锚点；不能用实际结局替代当时风险评价|
|Q5 Confidence|医生对本时点判断的把握|由临床团队另行冻结量表；不与模型自报confidence合并|
|更新条件|何种新证据会改变判断；可接受复评时机|自由文本及明确条件；同一动作也可在新证据下继续合理|

Q1在当前文档中保留为临床问题／关键未知识别，待原方案核对后映射；不得擅自宣称已恢复原方案Q1文字。

### 5.3 三Mode草案

- `CONTINUE`：当前证据足以支持继续所评价的根治切除路径，无需先解决足以改变该路径的关键缺口；须写明继续到哪一步，不保证实际执行或治愈。
- `PAUSE`：关键未知、冲突或可纠正条件可能改变当前路径；先采取针对性行动再复评。不是无限等待或暂停全部诊疗。
- `EXIT`：已有证据支持放弃或改变当前拟推进的根治切除路径；须写退出范围、替代管理及是否复评，不等于永久退出一切手术。

术中“探查后、具体操作前”不能直接沿用只含`CONTINUE_NO_NEW_STAGING`的术前动作解释。若允许在此时点选择切除、血管重建、中止根治或仅探查／分期，动作空间须由临床团队补充定义；不能为了生成HTML就把历史实际Whipple设成答案。

### 5.4 试评前仍需临床团队决定

1. 正式评审人数、独立性和至少两份有效性通过是否足够；临床Reference是否要求更多人数。
2. Q1–Q5正式字段、Severity/Confidence锚点、分歧处理和Acceptable Mode Set形成规则。
3. 术中和术前是否使用不同任务包／动作表；20动作中哪些只是候选索引，哪些需拆分。
4. 历史病例采用当时指南还是现代规范重评，并固定知识库版本。
5. 审核者能否被认定为真正独立，以及材料范围不足时的补源程序。

## 6. 当前审核产物如何使用

新合同支持将FAIL/PENDING及逐段修订存为研究者产物，由程序生成新的机械分区；新分区仍`NOT_ASSESSED`，必须重新审核。旧三个compiled文件及模型输出均不覆盖。程序只核验审核记录及hash，不核验临床判断是否正确。

下一批优先安排独立材料审核者审核SCALE-01术中包，SCALE-04保留为时间／复合文书反例。完成真实独立审核、临床表单冻结及来源缺口处理后，才生成实际许可包；本轮不将AI生成的审核草稿冒充为已完成的独立人工审核。
