# P2 验证修复与评审流程调整：实施回执 v0.3

2026-10-23。执行用户本轮“调整整个流程，往下推”的请求。当前主流程见同日《P2-重建验证与医生盲评衔接流程-v0.3》，标注规则见《P2-重建标注手册-v0.1》。本轮已完成验证代码修复、流程登记工具与首批独立材料准备；实际人类重建标注、IAA、正式医生盲评与临床Reference尚未产生。

## 从哪些问题改起

v0.2评估器按mention端点比较关系，并仅在gold已有pair内计算预测分母，会漏掉范围内多余错误边。旧版本已保存在本轮私有baseline目录；v0.2 release和输出未覆盖。新评估先独立对齐mention，再做不使用关系标签的事件一对一最大匹配，按事件比较去重后的有向关系。

| 合成反例 | 旧评估 | 本版 |
|---|---:|---:|
| m1/m2属于同一事件，gold用m1、预测用m2连接同一后继事件 | 关系recall 0 | recall 1 |
| 1条正确预测加2条scope内多余边 | precision 1 | precision 1/3 |
| 上述预测在相同分数阈值下 | 曲线precision 1 | precision 1/3 |

这些是程序口径的反例回归，不是临床准确率。完整scope内未标正边按无关系处理；人工明确uncertain的pair另记未评估，并给曲线precision上下界。scope外预测单列，不能混入范围内FP；真实gold必须声明可执行source_windows、独立标注者和裁定记录。

新增Decision–Decision和process-link分项指标；共指保留pairwise并增加共同mention上的B³。漏节点、未提议边、错方向、重复事件边、额外边和错误合并/拆分分别进入相应计数。跨算法版本的mention按来源/原文范围/类型对齐，不能假定signature参与生成的ID始终稳定。自由文本字段字面一致率不是医学语义准确率。

## 已落实的新评审流程

小规模完整原文独立重建标注用于验证算法；全部正式盲评包增加有效性门槛，通过后才填Clinical Reference。医生只flag结构问题，不现场修改后继续评分。独立结构裁定记录具体错误根、依据与规则，修订包重新核验来源/时间/遮蔽，并由其他仍盲的医生重评。

台账保存packet hash、版本、父版本、原自动proposal根、责任人、记录时间、问题标记、结构裁定、接触史和绑定表单的临床评分。原记录不可覆盖，失败或后续结构问题使相关评分隔离；合法封存评分不因之后才接触未来资料而被反向改写。代码检查已登记的接触史，不能自行证明实际人员未见过材料。

合并可涉及一个正确父包及一个重复父包，因此“受结构修订影响的原proposal”与“裁定确认出错的原proposal”分开。未评审、医生疑似问题与已确认错误分母分别保留。未知或尚未取得证据不自动使checkpoint无效；包遗漏和未来泄漏另行核查。默认2份有效性通过是本地登记策略，正式研究人数须预先按方案冻结。

使用完全虚构的本地流程演示已跑通：初始包被标记→结构裁定→新版本→另外两位虚构评审者通过→记录两份虚构表单响应。演示数据只用于检验状态转换，没有真人评分或临床答案。正式评审材料尚未由程序自动生成，也没有上线医生UI。

## 独立调用观察：有实际分歧和失败

新增read_write/read_only/refresh/bypass。replicate编号不进入prompt；bypass的每次响应、失败和usage独立保存，原cache不被覆盖。重复实验固定kimi-k3、temperature=1、thinking disabled、无传输重试，不为成功而补抽。

完成两类合成任务各3次真实API调用，6次均未读cache：

- 固定规范化：2次通过结构与引用检查，1次非法JSON/schema。两个有效重复的mention集合Jaccard为2/3；共享mention字段有措辞或归属变化。
- 固定节点与上下文的关系分类：3次通过结构与引用检查，原始及校验后的标签为supersede、revise、supersede。三个成对比较中只有一个相同，成对label一致率1/3；多数标签占2/3。

这些只是两个虚构输入的稳定性观察，不能估计真实人群准确率或泛化。也不能因为其中两次相同就认定多数标签正确。第一次实验原始summary、逐次回答及失败均保留，后续summary_analysis仅重新分析同一观察，没有新增调用或删除失败。

## 首批标注准备

从49名开发患者的冻结资料准备6个局部范围，共132份完整源文书。包括2个随机完整来源、2个零命中来源、1个反馈线索挑战和1个多动作挑战，各范围来自不同患者。分层仅供开发打磨规则，不能推广到P0。

A/B两套原文材料逐字相同，无程序高亮、图边或signature预填。抽样原因和原始映射只留研究者目录。anchor附近范围包含前后3天代理时间的所有交付文书，并保留精确时间未明的文书；这不是episode规则或临床盲材料。需要范围外资料时记录请求并同步更新两套材料。

每份标注表当前为空、状态INDEPENDENT_DRAFT、范围完成声明false。独立完成后可先编译逐字引用并用inter_annotator入口测一致性，不需要伪称一方已经是gold；分歧裁定后才生成ADJUDICATED重建gold。编译器只定位引用，不代替人类标注。
