# P2 文书模式与证据演化优化 v0.3

本次只改候选组织和证据比较，不改研究范围、标注手册、P1门槛、A/B/C标注或Clinical Reference。开发依据是固定10例中的01、06、10三例探查；10例重跑仍属开发试验。

## 两条原则与处理顺序

1. 判断具体选择是否属于胰腺肿瘤诊断分期、可切除性及根治路径评估管理。包括尚未承诺手术、补充证据、暂缓和不推进手术。
2. 比较该管理问题的前后候选之间是否有决策相关临床证据演化。首次可见的具体选择可作为过程起点，不声称两轮演化；相同动作可以是新判断；新文书和新措辞本身不构成新证据。

原始资料 → FHIR来源资源并读回核对原文/hash → 文书类型、段落、时间、动作词提出原句候选 → 整理同文安排及旁证 → LLM核查范围与记录用途 → 按同类管理问题提出前轮比较对象 → 提供旧临床原文、两轮间原文和同文选择前段 → LLM判断证据演化 → 引文及时间防护 → 输出候选checkpoint与管理过程。

## 文书与段落怎么用

`document_flow.profile`结合目录标题及正文头区分入院、首次病程、查房、术前小结、术前讨论、手术记录、术后病程等。目录名为“胰腺癌”而正文为“入院记录”时仍识别为入院记录。未知标题继续使用动作词兜底。

`paragraph_role`记录病史、诊断依据、鉴别诊断、当前计划、术前准备、病情评估、探查等用途。它是给模型的上下文，不是准入门槛。诊断依据中的“肌钙蛋白升高，拟完善冠脉CTA”仍提出候选。

术前小结/讨论中同一术式、兼容排期的多条安排，暂时组织成一个模型输入，保留每个原句及跨度。不同日期、取消/改变、再次评估、条件或备选方案不机械合并。这是输入整理，不是确认same_event。选择前窗口取各成员中最早的选择边界，避免后面的安排泄漏进选择前状态。

仅已观察到的完整通用未来探查句、表单字段和同意书完成句改作旁证，原句不删除。一般情况、营养状态和手术风险等评估仍交模型核查，不能仅凭模板相似度排除。

跨文书只检索更早同术式安排并附原文，不硬合并。模型如判断“仅记录已有安排”，必须引用更早安排；否则降为记录用途不确定。更早安排引文无效时，仅该关系降为不确定，不能抹掉独立核实有效的当前选择引文。小结若是唯一可见选择仍保留。

## 模型输入与输出

每个候选单独请求，禁止把更晚候选的上下文拼入更早候选。

第一次请求增加：具体文书类型、段落用途、正文/创建时间差异标记、同文成员原句、更早安排及其时间。输出在原有scope、role、时间性质、问题、动作、依据之外增加：

- `record_function`：新选择/评估、记录已有安排、历史线索、不确定。
- `prior_plan_supports`：逐字引用更早安排，不能用当前安排冒充。

第二次请求明确前后两个候选、各自选择时间/时间上界/检查实施时间/文书时间、比较范围和原文。除两轮间材料，还提供允许使用的更早临床文书及前轮已引用事实。更早影像/检验仍按既有窗口和已带入事实处理；这不是完整state认证。

输出增加`evidence_character`：新患者信息、明确复评、混合、仅重述、仅计划/表单、不确定。`supports`引用临床信息，`connection_supports`单独支持连接；两端各有引文不证明关系。

更早相同文字检索只提示“之前出现过相同表述”，不证明同一次测量。重复评分不能仅因换一份小结就叫新增；明确重新测量/复评且数值相同仍可保留新轮。无法判断同次还是复测时保持不确定。

前轮比较优先已保留、时间可排序、相同粗管理类别的候选；历史检查可用同文叙事先后。管理类别只是检索索引，模型仍判断是否同一具体问题。该比较对象不是已确认的临床前轮，漏提候选和并行管理仍可能影响比较。

## 时间、术中和术后

正文时间、创建时间、检查时间和报告可得时间分别保留，不自动择一为真。检查时间只约束未知选择时间的上界。上界窗口不是已认证的选择前材料。

术中候选保留探查发现，当前术中诊断/选择及其后执行内容不进入该候选的选择前段。手术开始时间仅为阶段代理，手术期间新报告无法排序时待核。

同日术后文书逐字复制唯一已定位术中选择时，保存为该选择的二手旁证；不能以术后文书时间另造一次术中判断。非逐字复制、匹配多义或时间不清仍留待核，不泛化为所有术后决策无关。

## 版本与验证边界

配置：`config/p2_auto_checkpoint_v03.json`。代码及依赖快照、版本diff、81项测试回执、固定10例真实调用和逐字引用核查在`private/p2_auto_checkpoint_v0.3_20261025/`。

旧版本和新版本的候选数量差异用于调试，不计算临床precision/F1。引文逐字校验只证明引文存在，不证明语义判断正确。输出是研究候选，FHIR Basic承载研究注释，不伪造ServiceRequest。仍未生成正式医生/Agent盲评包。
