# P2 判断定位与原文回放：第一版实现及开发检查

版本：Decision-IR v0.1，2026-10-22。基于此前 FHIR 回放方法 v0.1.1。**现在可以批量定位并组织供复核的原文判断；尚未自动确认独立决策点、完成 episode 划分或生成正式盲评包。**

## 1. 这次实现了什么

主线是：原始文书 → 连续原文中的判断/执行/反馈候选 → 同主题前后关系 → 研究者复核。FHIR 承载原文及来源；Decision-IR 是本项目用于记录判断位置和关系的中间结构。医生的可接受动作集合仍来自盲评，与历史采取了什么行动分别保存。没有把未发生过 MRI、没有反事实结果等情况设为本轮检索的排除条件。

**三个概念分开：**

| 名称 | 本版含义 | 不能据此宣称 |
|---|---|---|
| 原文单元 | 同一文书内一段连续文字，可含多个动作和条件 | 一个单元就是一个独立决策点 |
| 当前判断候选 | 措辞和语境支持当前的评估/安排，值得优先复核 | 已确认属于根治性切除决策 |
| 关系候选 | 同患者、同具体主题、较早记录与当前记录的连接提议 | 已证明因果、同一 episode 或某行为执行了此前计划 |

没有修改 P0/P1 成员；没有借用旧 P1 PASS 作为本轮门槛。输入是此前检索与目的性选择形成的 **49 名开发患者、5,199 份文书**，不是全部 P0 的随机验证样本。

## 2. 规则怎样执行

```text
逐份读取原文，登记患者、来源编号、全文哈希、文书类型、正文时间和创建时间
    # 来源/时间分开保存；创建时间不能默认为当时证据可见时间。

按句号、分号和换行取得连续原文单元，记录起止坐标
    # 不截断否定前缀；不把不同文书拼成新的临床事实。

检索：适应证判断、切除/操作安排、先处理再手术、再评估、执行和反馈措辞
    # 覆盖不同胰腺术式与“定于…下行”；PTCD、ERCP、营养等保留动作提及。

检查局部语境，再赋予角色与复核优先级
    若“是否/有无”或否定前缀覆盖肯定适应证词 → 不输出肯定解释
    若“定于/拟/计划”约束日期、麻醉下行 → 保留计划，不误作已执行
    若出院指导描述“如连续…可拔管” → 指导语句，不当成实际引流反馈
    若既往证据之后另有明确“目前…具备手术条件” → 保留当前结论候选
    若为POSTOP但存在新的安排 → 仍保留；单纯营养支持另标路径关系待核
    若历史、模板、其他操作或叙述时点不清 → 保留为待核，不删除患者
    # 一份文书可同时含历史、当前判断、执行和未来条件，不由文书标题一票决定。

为各具体主题，寻找同患者、严格更早的相邻原文；判断候选另找前一次判断候选
    # 同时间不硬排；“手术”泛词不单独连边；跨就诊单独标记。
    标记：同文复述待核 / 同动作再次判断待核 / 动作提及不同待核
    # 同样出现PTCD可以是首次计划、失败后再安排或重新确认；全部保留，禁止按24/48h合并。

输出原文卡、候选关系和审计队列，临床决策点与episode计数留空
    # 研究者先核对关系和截点，再制作医生盲评的时点材料。
```

代码集中在 `scripts/cohort_construction/p2_decision_ir/`，扩展词法、动作和主题分别可在 `extract.py` 的 ADDED、ACTION_PATTERNS、TOPICS 中查到。旧标签仅作检索信号；旧24/48小时候选链没有调用。每患者 visit 指原系统就诊索引，**没有将其定义为 episode**。

## 3. N01 给出的实际规律

同一患者的四份既有复核记录均被自动定位并保留：

| 顺序 | 原文中的判断含义（概述） | 本版处理 |
|---|---|---|
| D01 | 胆红素高，安排 PTCD，等待条件改善后手术 | 保留条件与动作在同一原文单元 |
| D02 | 管道脱出、引流不畅，拔管并再次安排 PTCD | 不因属于术后记录而阻断；不与D01合并 |
| D03 | 重新查看胆红素后再次提出 PTCD | 保留为再次判断候选，是否新决策另核 |
| D04 | 引流仍不理想，提出 ERCP 与后续手术条件 | 保留不同动作及条件，并连接此前判断供复核 |

程序在胆道主题上提议 D01→D02→D03→D04 的前一判断关系；前三步出现相同动作，最后一步动作提及发生变化。**这些是可检查的关系提议，尚非自动证明的因果链。**四个位置是已有开发病例，命中4/4不作为独立验证准确率。

N02 的减黄并营养支持、N03 的营养条件改善等待、N04 的身体条件不宜手术，也定位到既有锚句。N05 的入院叙述涉及此前评估，仍留待核，没有把入院记录时间直接指定为首次作出判断的时间。

## 4. 抽样暴露的问题与修复

首轮按预定义五层各抽四名不同患者，共20条；修复后仍对同一来源复查，不以新抽样替换失败案例。以下为分析者查看原文的开发结论，不是医生 Reference：

| 问题 | 具体处理 | 回归编号 |
|---|---|---|
| 术后文书被排除出当前判断 | POSTOP可含新计划，另核与根治路径关系 | IR021、025 |
| 拟/定于在麻醉下行被当成已执行 | 未来算子约束执行词；保留真正“已行”对照 | IR022 |
| 出院指导阈值当成实测反馈 | 指导与观察分开；出院后确有实测值不能被反向误删 | IR023、026 |
| 既往证据污染当前结论 | 分句检查明确当前判断，保留历史提示而不整句降级 | IR030 |
| 纠正执行后漏掉预定 ERCP/活检 | 扩展预定操作词法；无关操作仍保留待核 | IR031 |

此前的否定、疑问、模板、操作对象、术后/腹膜后、诊断性“新辅助治疗后”、源坐标和时间排序等也迁移到本版测试。最终共 **32 项 IR 测试；连同所依赖的旧检索、动态路径、FHIR及回放测试，共95项通过**。测试验证程序反例，不证明临床语义识别已经完整。

零命中复核中仍有检查建议、化疗安排、出院计划。它们可能含医疗决策，但是否涉及根治性切除路径需要上下文；保留全文索引，未据零命中排除患者。常规术后营养支持也不能直接算根治路径判断：本版单独标记74个这样的原文单元，继续供关系复核。

## 5. 最终结果怎么读

最终开发运行 `run07`：

| 输出 | 数量 | 含义 |
|---|---:|---|
| 原文单元 | 3,036 | 多种角色总数 |
| 判断候选 | 1,262 | 包含历史/语境待核候选 |
| 当前判断候选 | 752 | 上一行子集，尚未确认研究相关性或独立性 |
| 含当前判断候选的文书 | 462 | 49名开发患者均有命中 |
| 执行提及 / 反馈提及 | 1,124 / 190 | 提及，不等于一个独立事件 |
| 指导语句 / 支持线索 | 129 / 331 | 保留原文，分开解释 |
| 关系提议 | 1,719 | 可重复主题/选择器，不是episode数 |
| 零单元文书 | 3,743 | 索引仍在；不代表无决策或资料不可用 |

每患者“当前判断候选原文单元”的中位数为12，**不能回答每患者有多少独立临床决策点**，后者目前留空。旧标签在相同输入中优先检索到146份文书，本版全部保留，并增加316份；这是检索口径变化，不是新增316个正确决策。

与本轮首个开发运行相比：共享单元3,030个，新增6个、不再发出7个；193个由执行提及转为判断候选，19个由反馈提及转为指导。当前优先级从540变为752：共享单元258个上调、51个下调，另有新增单元。患者与原始文书未改变。中间run02–run06也保留，但都属于未发布的开发过程；最终实现以run07及本次提交为准。

## 6. FHIR、回放与盲评的连接

N01 的35个IR单元已经与20份既有 FHIR DocumentReference 按患者映射、来源编号、原文哈希和坐标核对连接。这里只引用原始文本资源，没有把算法候选伪装成临床医嘱、Observation或专家Reference。FHIR资源同文一致不等于原版本在历史时点确实可见。

本版复核卡含当次行动及后续内容，是研究者材料。进入盲评前还需核对：真正的判断片段边界、当时可见版本、历史行动遮蔽、同一问题内重复/再次确认/新判断的关系。**临床动作是否可接受由医生盲评；某一动作之后能否继续历史回放另行记录。**专家Confidence保留；IR的confidence为空表示程序未提供校准置信度，两者互不替代。

## 7. 下一步具体做什么

优先用本版的关系复核卡，对“同动作再次判断”和“动作变化”各取一组完整上下文，明确记录为何算复述、再次确认或改变计划。再从确认的判断句确定遮蔽边界，产出时点state草稿。关系复核字段和遮蔽规则冻结后，才扩大到新的患者做独立开发外检查；无需先等待构建完备的反事实环境。

可复现说明见模块 README；规则问题清单、95项测试回执、代码/输入/结果哈希见模块 release 文件。原文和患者索引只放私有目录，不进入Git。
