# P2 动态评估样本探查：怎样找、为什么这样找、实际找到什么

2026-10-21，开发探查 v0.1。范围：固定 P0 全体 2,707 人。本轮不修改 P1/P2 正式纳入条件、episode 定义、患者成员或专家 Reference。

## 1. 本轮研究问题

**把可切除性相关决策视为一个动态过程：当前是否推进根治切除路径，若暂不直接推进，先处理什么、等待什么、何时或以何条件再评估。**

减黄、营养或其他身体条件改善，属于这个过程；不要求它们必须是“补证据”才能进入研究范围。文书已把高胆红素/肝功能问题与“先处理、之后手术”相连时，记录的就是当次对手术时机和路径的安排，而不必等到另一份文书写出“可切除/不可切除”。

这个范围仍以文字支持的路径关系为依据。一次 ERCP 本身可能服务于诊断、新辅助治疗、姑息或其他目的；仅有操作名称时，不能替原文指定原因。这里是区分记录所表达的安排，不是在排除条件优化这一类决策。

## 2. 为什么这样找：指南线索到检索假设

来源是用户提供的 NCCN Pancreatic Adenocarcinoma v4.2026（2026-09-11）。本地 PDF 位于项目 `references/guidelines/`，校验值见 `docs/nccn-pancreatic-v4.2026-source.json`。下面是研究者的操作化，不是指南定义的研究决策点分类。

| 指南中的临床思路 | 本轮据此寻找什么 | 指南位置；PDF 页码从1起 |
|---|---|---|
| 胆道处理与手术时机、手术延迟和新辅助治疗有关，不能仅凭黄疸要求所有人引流 | 减黄/梗阻/胆红素与等待改善、再评估或后续手术安排相连 | PANC-B；37；MS-16–17：94–95 |
| 可切除疾病后仍有治疗路径选择，医学适合性与解剖类别不同 | 感染、营养或其他身体条件与暂缓/条件性手术安排相连 | PANC-2；12；PANC-D 1/5：39 |
| 可先治疗，之后重新评估，而非一开始就永久确定能否手术 | 先新辅助/转化治疗，再评估手术或切除机会 | PANC-2/3/4；12–16；PANC-10/10A：25–26 |
| 治疗反应与手术机会需要重新评价 | 治疗后复查/反应与当前手术意见或具体计划相连 | PANC-4/4A、PANC-D 1–3/5；15–16、39–41 |
| 某些阶段需要进一步诊断、分期或取材；与生理条件改善不同但可共存 | 待明确证据、取得结果后再决定的比较情境 | PANC-1/3、PANC-A 1–2/8、PANC-B；10–14、29–30、37 |

这样做的理由是先寻找**条件/证据—临床解释—路径安排**之间的关系，而不是把“血管受侵”“减黄”或“第几次化疗”单独认作决策点。理由不必与安排写在同一句；明确的具体切除计划仍可有候选价值，不能因为没有写全这一结构而被排除。

## 3. 实际怎样找：分阶段留痕

### A. 先预定义宽检索，再查看结果

`p2_dynamic_pathway_probe/rules.json` 在运行前写明五类词组、完整正则及各自指南理由。对 265 份缓存逐一验 SHA-256，逐患者核对原始源行数。共读取 210,144 行，按既有医师/临床上下文文书范围进入 143,712 份非空正文；未使用 P1/QC 状态、旧 P2“当前意见”标记或正文必须有“胰”字的过滤。

同段的一句或相邻两句中，寻找手术/切除锚词及其前后220字符内的相关线索，保留完整连续原句和偏移。220字符是宽检索参数，不是临床边界；两句不能跨换行段落拼接。类别可重叠，不赋临床动作，不压缩episode。

### B. 固定抽样，先观察宽检索错在哪里

每类抽4名不同患者，尽量各含2名有明确历史措辞、2名无该措辞的患者；不足则补抽。种子20261021。患者先抽、再随机取其命中，避免记录多的人主导抽样。原4个开发病例所属患者只从新抽样中排除，不从检索总体排除。

得到20条、20人。逐条看片段和文书类型后，发现大量“术后/腹膜后”的字面“后”、风险模板、既往史和临床研究标题误配。**这些结果没有被计为决策点。**

### C. 根据已观察问题开发关系提示，再另抽样

新增 `relation_rules.json` 与 `prioritize.py`：优先明确的条件—手术、治疗—重评等关系句式；原30,409条宽检索条目全部保留。关系规则是观察结果后开发，不能伪称在首轮前就已确定。

每类再抽4名不同患者，种子20261022，20条共18人；与B的选择方法不同，且有跨类别重复。关系提示仍可能指向旧意见、术后经过或其他操作，不能当临床确认。

### D. 针对明确的减黄安排做定向查看

为回应“先处理条件也是研究过程”，在D01宽检索结果中查询等待/改善与手术的明确连接，要求源文书有胰或肿瘤线索，再按医师查房/会诊优先、片段较短、稳定来源键排序，取前12名不同患者。完整查询及排序由 `targeted.py` 保存；这是一组**目的性开发样本**，不是随机验证集。该查询仍会混入“待检查后做ERCP”，因此继续核对操作对象。

### E. 回原文、回患者上下文

三组选择共涉及49人，重新读取其全部范围内5,199份文书，逐人核验源行数。查看了20+20+12个检索条目，可能涉及同一文书/患者，不是52个独立决策。重点复看10份完整文书，对最后五例再看同一源就诊中的相关原句及其他文书索引。没有把一份原文改写或拼接成新事实。

五例从上述队列中由分析者选择，理由是能说明动态过程及其不同限制；不是随机抽出的五个阳性结果。五名患者均不同于原来的四名患者。选择ID、原文坐标、源文书、两套时间和解释保留在私有复核记录。

## 4. 检索规模与局限

| 检索家族 | 宽检索条目 / 涉及患者 | 明确关系提示条目 / 涉及患者 |
|---|---:|---:|
| D01 减黄与条件改善 | 9,030 / 1,061 | 90 / 56 |
| D02 患者条件与暂缓 | 3,105 / 2,467 | 41 / 28 |
| D03 先治疗再评估 | 7,395 / 618 | 243 / 134 |
| D04 治疗反应与手术安排 | 1,232 / 82 | 9 / 5 |
| D05 补证据的比较情境 | 9,647 / 2,519 | 110 / 81 |

宽检索共30,409个类别条目、17,557份文书、2,622名患者；这些大数字主要说明宽召回及噪声，**不是2,622人存在已确认决策**。明确关系提示也不是正确数、敏感度或最终纳入人数；不同家族重叠，且仍有误配。

本轮读全部交付历史，未自动限研究期。正式P2仍要限定研究期内episode。这里不估计每人中位决策点数，也不能与旧300人候选链数量直接比较。

## 5. 五个新患者的实际情况

以下均为分析概括；逐条原文和完整源文书另存私有原文卡。

| 新例 | 文书里出现的安排 | 在相关记录中还能看到什么 | 对动态评估的启发 |
|---|---|---|---|
| N01：胆红素仍高、调整引流 | 胰头病变伴梗阻，胆红素持续升高，先引流，降至适合水平后再手术 | 后一记录说明PTCD引流不畅、胆红素虽降仍高，改ERCP处理；后续有明确的胰十二指肠切除计划 | 当次处理条件、复评处理效果、调整处理与手术安排，构成可以追查的过程；不必每步重写解剖可切除性 |
| N02：减黄与营养补充后手术 | 肝功能和胆红素问题明确，先减黄并补充营养，改善后安排胰十二指肠切除 | 后续术前小结/讨论有具体切除计划；也存在并行记录与不同拟定日，需核对 | 不是抽象地“等检查齐全”，而是明确在安排手术前的条件改善；语义相关性和精确时间可用性分开判断 |
| N03：营养治疗后仍未改善 | 营养补充后白蛋白未明显上升，进一步查低白蛋白原因，待营养改善再手术 | 较早记录已计划胰体根治切除；后来又有具体切除安排 | 优化与补证可同时存在：既处理状态，也澄清为什么未改善；不能强制归入单一原因类别 |
| N04：新辅助后身体条件成为限制 | 营养差、心功能不全，当前不适合全麻，出院后加强支持并随访 | 同就诊早期拟胰十二指肠切除；中间有营养支持和等待好转的安排 | 肿瘤路径开放并不保证患者当前能进入手术；评估可因身体条件而暂不推进，不能标成解剖不可切除 |
| N05：治疗后再提出手术机会 | 化疗后复查提示病灶缩小，病史转述具备手术机会，入院寻求手术 | 后续首次上级查房给出肯定意见，术前文书有具体切除计划 | 可以由入院病史找到早前重评线索，再追原始门诊/MDT或当次确认记录；入院日不是已证实的最早决策日 |

N01最能说明本轮目标：**条件尚未达到 → 处理条件 → 处理效果不理想、调整措施 → 后续切除安排**。它支持把减黄纳入动态评估研究；不证明医生每次选择正确，也不意味着其中每条文书都应独立计一个checkpoint。

五例均有可用的路径安排语义，但部分正文头与系统日期不一致；相似的当前用语也会被重复记录。因此，这些是已核对语义及相关上下文的开发病例，不是五个已完成时间认证/医生盲评的episode。

## 6. 检查到的问题怎样处理

| 稳定编号 | 可能造成的错误 | 本轮处理与验证边界 |
|---|---|---|
| DYN-001 | 术后/腹膜后中的“后”被解释为将来再手术 | 增加明确关系优先级及反例/对照；原命中仍留存，不据此删患者 |
| DYN-002 | 风险模板写的感染/恢复差被当作当前患者状态 | 局部风险模板不进入相应关系优先级；当前感染暂缓的阳性对照保留 |
| DYN-003 | 试验标题中的局部进展期/不可切除被当疗效或重评 | 仅此不进入疗效—安排的明确关系提示；没有把试验入组当新决策 |
| DYN-004 | 糖尿病既往史与“否认手术史”相邻被误连 | 相邻共现仍保留审计，不因这种文字生成条件性手术提示 |
| DYN-005 | 泌尿、脊柱或其他操作的暂缓语句被当胰腺根治路径 | 增加局部对象/同意材料待核提示，并核对完整原文；不排除整个患者 |
| DYN-006 | “首先考虑……新辅助治疗后”诊断小结被当先治疗再评估 | 增加诊断语境提示及反例，保留其中可能有价值的当前手术计划，人工区分它与未来治疗顺序 |

前三组抽样里也发现某条切除安排的完整文书指向十二指肠原发肿瘤，以及IPMN相关来源待核的记录。不能把胰十二指肠切除术名直接等同PDAC，也不因为一个时点的鉴别诊断就重筛P0。作用层级是**具体记录、目标病变及相应episode的待核**。

这轮完成了搜索、开发抽样、关系优先级和局部提示，并保存五例原文卡；没有完成全量临床语义分类、全量时间角色/手术对象识别或临床独立验证。26项合成测试保证对应代码行为，不是临床准确率。

## 7. 伪代码、程序与记录位置

```text
从全P0范围内的原始临床文书检索：
    找手术/切除表述附近的条件、治疗、重评线索
        限同段一句或相邻两句；保留原句、来源和偏移
        # 先宽召回，避免只找“可切除/不可切除”而漏掉条件性安排

按预定义规则抽样查看：
    每类先抽患者，再抽其一条命中；历史线索与非历史线索都看
        # 多记录患者不能主导样本；没有“既往”不等于一定当前

根据首轮观察，另建关系优先级并再次抽样：
    优先“待条件改善后手术”“治疗后再评估”等明确连接
        # 术后、腹膜后、风险模板不能靠字面误当路径更新

对明确减黄安排定向回找：
    保存查询、排序和选择理由；与随机抽样分开记
        # 找有解释性的病例，同时保留操作对象错配等反例

回到完整源文书和患者上下文：
    核对目标病变/操作、当前还是历史、已发生还是未来计划
    保留两套时间、意见差异及原始来源
        # 重复计划、引流操作和随后手术都不自动等于多个独立决策

输出候选记录与复核解释：
    不自动产生临床GT、Acceptable Mode Set或episode边界
```
