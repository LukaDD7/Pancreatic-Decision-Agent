# 指南覆盖哪些决策，四个病例有什么共同结构

2026-10-21，解释性研究备忘录 v0.1。依据用户提供的 NCCN Pancreatic Adenocarcinoma v4.2026（2026-09-11），原始 PDF 共 167 页，来源与校验值见 `nccn-pancreatic-v4.2026-source.json`。

本次按完整专业版的总流程、相关原则及讨论梳理临床决策范围；重点阅读诊断/分期、手术路径选择、治疗后评估、术前减黄、术中判断、术后及复发管理。不是逐项评价所有药物、剂量、放疗技术或参考文献。下列“范围”“层次”“共同结构”是研究者对指南的归纳，不能称为 NCCN 正式定义的研究决策点分类。

## 1. 指南覆盖的是整个诊疗过程

指南的入口并不要求已经完成病理确诊：PANC-1 从临床怀疑胰腺癌或胰胆管扩张开始。后续不仅判断能否切除，还包括选择证据获取方法、治疗顺序、非手术治疗、术后和复发管理，以及支持治疗。

| 临床问题 | 指南纳入的选择举例 | 核对位置：指南编号；PDF 页码 |
|---|---|---|
| 诊断及分期怎样澄清 | 胰腺专门影像、疑难病灶补充检查、病理取材、必要时分期腹腔镜、MDT 评估 | PANC-1、PANC-A、PANC-B；10–11、29–37 |
| 初始应进入哪条治疗路径 | 直接手术、新辅助治疗、因医学原因不能手术时的其他管理；可切除性和远处转移参与该选择 | PANC-2/2A、PANC-3、PANC-C；12–14、38 |
| 手术或抗肿瘤治疗前需要先解决什么 | 是否引流减黄、如何取材、患者条件优化及治疗前准备；不是每项准备都等于补证据 | PANC-B、PANC-D 1/5；37、39；MS-16–17：94–95 |
| 治疗后是否改变路径 | 再分期、治疗反应评估；考虑切除、继续或调整治疗、以后再评估 | PANC-4/4A、PANC-10/10A、PANC-D；15–16、25–26、39–41；MS-15：93 |
| 术中是否仍应切除、怎样切除 | 排查远处病变，判断能否完成目标切除、是否需要血管处理；发现不可切除后的替代处理 | PANC-8、PANC-E；22、44–45 |
| 术后怎样管理 | 是否及如何给予辅助治疗、恢复情况和基线评估、随访及疑似复发的处理 | PANC-5/5A；17–18 |
| 复发或晚期疾病如何管理 | 局部复发的 MDT/外科再评估，系统治疗、维持或后线治疗、临床试验；按患者情况调整目标 | PANC-6–12；19–28；PANC-G 总则：52 |
| 症状、营养、风险等如何管理 | 梗阻、疼痛、营养及支持治疗；胚系/分子检测和相关咨询也进入诊疗选择 | PANC-I、PANC-J；73–75；PANC-1/1A、PANC-G 总则 |

这些内容不是一套研究应全部纳入的清单。指南临床管理的范围，大于本研究围绕根治切除路径的范围。支持治疗可发生在不同阶段，也不能仅凭“支持/姑息”措辞判定患者永远不可能再被评估。

## 2. 最关键的关系：状态判断之后，还有路径选择

PANC-2 把“可切除疾病”与后续的“治疗决策”分列。即使属于可切除疾病，仍区分直接手术、新辅助治疗，以及医学上不适合手术时转入其他管理流程。最后一项的流程转引，不是把患者的解剖分期改成“局部进展”。

因此，研究上应区分：

1. **状态评价**：病灶及血管关系、转移情况、治疗反应、患者状态等。
2. **当前路径选择**：现在推进根治切除路径，还是先补充证据、先处理问题/治疗后再评估，或当前采用其他方向。
3. **具体执行**：怎样穿刺、置支架，采用什么术式或治疗方案。

三者会写在同一文书里，不能相互代替。例如“血管受累”首先是状态信息；“拟先治疗后评估能否切除”体现路径选择；“本次第几周期化疗”可能只是既定计划的执行。是否有新的手术评估，要回到具体语义，不能由任一词语或一次检查直接认定。

## 3. 四例分别落在何处

以下仅概括原来的 B02、B03、B06、B01，不作为临床正确性裁定或专家 Reference。

| 病例 | 当前问题主要是什么 | 文书中已作出的安排 | 须保留的边界 |
|---|---|---|---|
| B02：肺部感染暂缓 | 当前身体条件是否适于推进，并夹有后续取材/检查问题 | 当前不宜手术，先取材并等待进一步信息 | 不是解剖不可切除；不把该例直接套成长期医学不可手术；也不能因有感染就认定当时选择必然正确 |
| B03：减黄后重评 | 是否先处理梗阻，以及后续外科/药物治疗的顺序 | 当前先解除梗阻，改善后再评估 | 现在的分阶段安排已经发生，未来的重评尚未被这句话证明；减黄也可能服务于新辅助治疗，而非直接手术准备 |
| B06：转外科手术 | 当下是否支持继续外科手术路径 | 有肯定意见，建议转外科进一步处理 | 是明确推进意见，但不是最终手术授权；肺结节仍未定性，记录存在不表示其余不确定性均已解决 |
| B01：转非手术治疗 | 所述远处病变是否使当前不应推进切除 | 当前不推进，拟取病理后系统治疗 | 否定手术也是手术路径判断；不等于永久失去重评可能；邻近相反计划仍需核对，不能自动当新证据更新 |

所以，四例不是四种并列的“可切除性类别”，而是**不同原因约束下，对当前手术路径作出的安排**。若研究仅限“影像学判为可切除/不可切除”，会漏掉前两例；若研究关注“是否、何时及以何条件推进根治性切除”，四例都有相关性。

前两例也不能直接合并成一个“补证据”类别：感染、已知梗阻可能需要处理，而不是主要需要知道更多；同一患者又可能同时有未解决的诊断/分期问题。医学优化、信息获取和替代治疗可以共存。程序索引应保留理由和安排，最终可接受动作集合仍由专家按时点评价。

## 4. 从四例得到的可检验共同结构

```text
已有情况或证据
    → 医生在本次文书中的解释/评估
    → 对当前根治切除路径的安排
    → 下一步行动，或未来重评的条件
```

这一结构比“感染”“ERCP”“转移”四类病因词更可扩展。更值得定位的是：**临床记录把某种情况转成了对手术路径的选择或安排**。

可以据此寻找三种表述结构，而非限定四种疾病情境：

- **解释—选择**：考虑/评估/结合……，目前有/无指征、拟推进或不推进。
- **条件—安排**：因……暂不宜；先……，待/之后再评估手术。
- **治疗后—重新判断**：经过治疗、复查或外科/MDT 再评估后，当前拟切除、继续治疗或采用其他方向。

这是高解释性的开发线索，不是强制要求一句话具备全部要素。只有“拟行具体胰腺切除术”的当前计划，仍有候选价值；理由可能在别处，也可能没有明确写出。相关文书应按来源索引查看，不能拼成新的临床事实。

三个反例能限定范围：

- 只有影像描述“门静脉接触”，尚不能证明当次作出了手术路径选择。
- 只有“完成第六次化疗”，尚不能证明当次重新评估了手术机会。
- 后续病史再次出现旧的“无手术指征”，不等于按当前文书日期新作出了一次否定决策。

## 5. 完整指南提示的两个扩展方向

**其一，治疗后重评应重点覆盖。**PANC-4、PANC-10 及其脚注明确保留了治疗后再评估和可能切除的分支；PANC-D、MS-15–16 强调治疗反应，不能只照搬初始解剖分类或把持续血管影像异常等同于永久不可切除。因此，下一类样本应优先找“治疗后证据 + 当次重新评估 + 路径安排”，而不是按化疗周期直接切段。

**其二，证据需求随路径变化。**PANC-A 2/8（第 30 页）、MS-9–10（第 87–88 页）区别手术前与化疗前对病理确认的要求。不能把某一项证据在所有评估时点设为统一先决条件。PANC-1 也允许从尚未确认诊断的阶段开始评估；在固定 PDAC 人群内回溯时，不应把以后确诊的信息倒填成早期已知事实。

指南也涉及术中改变切除计划，以及选择性局部复发患者的再切除评估。但它们是否属于本研究核心 episode，取决于预先确定的终点和范围，不因指南出现相应分支就自动扩展。本备忘录没有修改这些边界。

## 6. 对 P2 的暂定表述

较符合四例和指南路径的研究范围是：

> 根治性切除路径的评估与管理：识别病历中对是否、何时、以及在何种前提下推进该路径作出的当次判断或安排。

这不是“只收能做手术的患者”，也不是收录所有肿瘤管理决定。一次化疗方案选择、一次支架操作，仅在它和根治切除路径的关系得到记录支持时，才成为这里相应的候选记录。

“候选记录存在”“可锚定为独立评价 checkpoint”“归属于哪个 episode”仍需分别判断。文字、文书类型和时间负责定位这些记录；指南提供临床问题和可能分支，不能直接给出本院某条文书的真实最早决策时间或统一的 24/48 小时窗口。
