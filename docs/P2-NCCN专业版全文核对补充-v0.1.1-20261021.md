## 对四例的直接影响

| 示例 | 核对位置（PDF 页码从 1 起） | 维持或收紧的解释 |
|---|---|---|
| B02：感染暂缓 | PANC-D 1/5（第 39 页）将术前患者状态优化列入新辅助治疗的作用之一 | 患者条件优化确实属于手术路径评估的语境；该页不能证明某例肺部感染必然禁忌手术，也不能把“等好转”自动解释为补证据 |
| B03：减黄后重评 | PANC-B（第 37 页） | 计划直接手术前并非常规引流；是否引流需结合胆管炎/发热、严重症状性黄疸、手术延迟或新辅助治疗等情况。研究应找“为何先处理、处理后如何安排”的记录，而非将所有 ERCP 认作根治手术决策 |
| B06：肯定机会并转外科 | PANC-A 1/8（第 29 页）、PANC-C（第 38 页） | 可切除性判断依赖专门影像、分期与多学科评估；转科或某条肯定意见是定位线索，不能自动证明已完成这些评估，也不直接充当 Reference |
| B01：当前转非手术路径 | PANC-C 脚注 c（第 38 页） | 远处转移影响直接切除路径，支持检索当前否定判断及其后续安排；需要保留“当前”“直接手术”的限制，不能从一次判断推定终身无再次评估机会 |

PANC-C 脚注 d 还明确区分局部进展与不可切除。因此，`局部进展`、`血管受累`等描述只能协助检索与核对，不能单独作为 P1/P2 排除条件，也不能自动生成 REDIRECT。

## 更值得扩展的模式

PANC-4 及脚注（第 15–16 页）、PANC-D 1/5（第 39 页）明确设置治疗后再分期、反应评估和后续路径选择。对本研究，可优先检验：

```text
既往治疗及其时间
    + 本次重新取得或审阅的证据
    + 当次是否推进手术／继续治疗再评估的明确意见
    → 治疗后重评的候选决策记录
```

这是依据临床路径提出的检索假设，尚未加入已运行的四类代码。仅有“第几次化疗”、单独一份复查影像或历史手术判断仍不足以确认新的独立决策点。指南的影像时间建议也不等于病历定位时应统一倒推 24/48 小时。

仍维持上版边界：候选记录存在、独立 checkpoint 可定位、临床选择是否合理，是三个需要分别验证的问题。此轮只更新来源与研究解释，没有改写患者原文、产生盲评 Reference 或重跑队列。
