# Semantic diff：v0.3 → HEWV v0.4

本次改变研究输入的语义，不是仅重命名。v0.3 contract、代码和输出保留，当前入口改为 `pancreatic_agent.episode_extract`；`timeline_extract` 仍复现旧版。

| 方面 | v0.3 | HEWV v0.4 | 研究含义与迁移 |
|---|---|---|---|
| 名称/范围 | 时间线优先四阶段提取 | 本院诊疗Episode与完整记录可见性契约 | 将episode、观测覆盖和原文单位写成可复用定义 |
| 起点对象 | 患者最早病变报告/外院引用可锚定 | 本院首次接触并观察病变；缺首诊时为最早可观测本院记录 | 不追溯全生命周期首次患病/检查 |
| first visit | 外院日期与本院起点可能混用 | 真正本院首诊与覆盖起点分开标记 | 起点与首次提问时刻分开；不能把检查时间称首诊时间 |
| 外院资料 | 后来文书的历史片段可前置 | 本院接收的独立报告，或当时已完成的本院全文中的引用 | 原检查日期不代替本院可见时间 |
| 回述重建 | hash/坐标绑定的片段生成-H事件 | 禁止从后来文书抽片段前填 | 旧review不能直接迁移，需要从原来源重做 |
| 文书单位 | 临床正文前缀、审阅片段 | 一个完整来源版本 | 不通过删除计划句构造未决策状态 |
| 诊断/计划footer | 可截断后保留前文 | 整篇保留或整篇版本待审 | 可能减少已认证资料，但不静默选择有利事实 |
| 混合版本 | 未来内容触发段落review | 晚时间只是候选，整篇待审，全文hash审阅或独立历史版本 | 不把每个未来日期都判泄漏，不删后文制造早期版本 |
| 文书标题 | 术前/术后和非临床模板可排除 | 不按标题自动排除已可见来源 | 保留真实护理背景与既往治疗记录 |
| 病理类型 | 自动限定诊断性取材类型 | 全部已可见病理保留 | 既往手术病理也是可用背景 |
| 影像呈现去重 | 同标题/同时间/同正文可合并来源 | 每条来源保留，不自动去重 | 原始实例数量与重复情况可见 |
| 检验 | 已报告全项目 | 延续，不按重要性/最新值压缩 | 与180例历史筛选脚本仍有区别 |
| 建档时间 | 不作临床时间 | 延续；可留在raw审计列 | 不要求源字段扰动后审计原文也完全不变 |
| 报告与接收 | 影像检查代理经review接受 | 延续显式代理；独立外院来源还需本院接收依据 | 无效报告字段不得退回检查；代理不当签发证据 |
| 阶段定义 | 固定四问，3/4固定同一终点 | 四个问题框架，checkpoint按证据更新显式绑定 | 不把阶段标签当临床状态、不强制四个不同钟点 |
| 缺失节点 | 部分自动候选/回建 | 缺可靠锚点即UNRESOLVED，其他阶段可保留 | 不复制截点凑完整四阶段 |
| 手术前边界 | 最早可定位具体胰腺切除拟术式 | 明确独立决策的最早一般建议，或具体计划复核 | 一般“限期手术”不能视而不见 |
| 既往医生建议 | 前缀截取时可能删掉 | 已可见就完整保留；独立/复核分开 | 两类任务不能混报同一个指标 |
| 配置 | 发现/分期override、evidence_spans | episode、source_scope、四个来源绑定checkpoint、task_mode、全文版本review | 禁止旧字段静默兼容，必须重审 |
| 默认自动化 | 可从最早腹部影像自动候选 | 初版需要显式review，程序执行整份记录规则 | 自动关键词候选生成尚未实现，不能宣称已批量认证first visit |
| 审计 | included/excluded及片段坐标 | included_whole/excluded_whole/unresolved_whole | 未知可见性与已知晚于截点分开 |
| 模型输入 | 同system prompt、独立四问 | 延续；复核模式明确改变问题措辞 | 问题hash留痕，context变化与任务变化分开 |

## 迁移步骤

1. 保留旧资料包与review，从患者完整来源数组重建，禁止使用旧context节选作新源。
2. 确认本院范围、entry及其证据，标记first visit是否只是观测起点。
3. 重新盘点最早一般建议与具体术式计划，明确独立决策/复核。
4. 显式绑定四个问题的报告/文书锚点，可共享、可缺失，不造时间。
5. 核对全文版本，未知整篇待审；影像代理/外院接收单独记录。
6. 输出病例级semantic diff，检查边界、来源集合及真实正文载荷变化。新旧源bundle hash必须相同，否则先做来源版本迁移，不能把来源变化归因于提取规则。

## 病例级 diff 的解释

CLI `--compare` 输出各问的旧/新checkpoint、计数、来源新增/移除及正文载荷差异。由节选改全文属于实质信息变化；外院-H片段取消属于回建规则变化。共享context不等于独立样本。

患者级diff仅保存在本地忽略目录。公开文档不包含真实患者的日期、正文或来源键。v0.4的合成测试验证规则执行，不能证明来源层无损、影像真实签发时间或临床评价正确。

## 后续补充：独立决策接口 v0.1

输入可见性规则延续HEWV v0.4，新增[独立决策接口](../contracts/v0.4/05_decision_interface.md)：自由文本/多建议输出改为PAUSE、EXIT、CONTINUE之一、一项首选动作及严格JSON。system prompt与动作/schema单独版本化。四问仍独立，无动态回放。该提示词变化需作为新的实验条件记录，不能与旧自由文本输出混作同一测试。
