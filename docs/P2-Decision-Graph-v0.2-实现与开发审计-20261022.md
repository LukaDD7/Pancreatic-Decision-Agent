# P2 Decision Graph v0.2：实现与开发检查

2026-10-22。接续Decision-IR v0.1/run07，新增 `scripts/cohort_construction/p2_relation_graph/`。本版已经接通语义模型与分阶段关系重建原型；没有确认独立临床决策点、完成episode规则或形成医生Reference。

## 本轮落实的审计意见

原文单元 → 带来源signature的Mention → 共指提议 → DecisionEventHypothesis → 分类型关系。Evidence、Action和Feedback另有独立类型节点。所有来源单元、失败、未运行候选和未确定关系均保留；不依据模型输出删去患者。

signature包含管理问题、对象、评估、拟采取动作、条件、目标、承诺，以及时间语义和逐字引用。`not_mentioned`与`uncertain`分开，不能推成明确阴性。规范化值仅为检索/比较索引，不替代原文。

共指和事件关系分阶段调用；不同阶段标签混用会被降为uncertain。单纯同动作、同文字、短时间或没有写新证据不能证明同一个event。reaffirm需正面重评/新证据依据；revise需评估、动作或条件改变的依据；supersede另需替代依据。精确引用校验只证明引用真实，不证明关系解释正确。

候选按同患者、管理问题字符相似度/主题与代理时间排序，取Top-K，不把所有记录发送给模型两两分类。未知问题保留召回余地。分类上下文含两端事件全部成员和中间文书，包括零命中文书；资料超预算、时间缺失和候选截断单独记账。没有引入embedding模型。

图校验覆盖共指传递性与不同事件冲突、事件内修订、合并后有向环、节点类型和动作不兼容。事件层的每个端点可解析到决策或辅助事件假设；全部仍为REVIEW。

## API与实际调用

项目已有博约密钥，既有外部凭证文件提供基础端点；无需从日程项目复制密钥。`/models`返回包括 `kimi-k3`。已将其设为 `config/model_provider.json` 默认值，新自动化可复用 `load_boyu_settings()` 和语义适配器。原通用 `LLM_*`配置契约保留，避免改变旧实验。

实际远程请求只发送了合成文本。本轮使用 `thinking.type=disabled` 完成结构化流程；服务返回模型字段 `kimi-k3`，并记录usage。接口响应不独立证明底层模型身份或临床能力。凭证没有写入报告、代码或请求回执。

早期开发运行保留了网络超时、非法JSON/schema和坐标校验失败。模型曾给“拟行PTCD”算错中英文混合字符坐标；本版改为返回唯一逐字引用，由程序定位坐标，禁止模型输出自行计算的offset。重复引用不能唯一定位时拒绝猜测。RG021覆盖该问题，其他问题登记见回归清单。

## 验证、校准与未完成项

新增RG001–RG025合成反例及对照，连同旧95项测试共120项通过；已迁移旧覆盖。另执行P1保护器105项检查通过，未更改P1规则或数据。项目原测试160项通过；首次执行环境缺少声明依赖openai，已在忽略目录补齐测试依赖，没有修改系统Python。完整回执另存。

评估入口已实现成对共指P/R/F1、关系macro-F1与混淆、候选边召回、正确类型边召回、范围内图完整性、review率及coverage–precision描述曲线。评估须输入独立标注、已裁定、范围完整且mention身份已对齐的gold。测试中的synthetic_fixture不构成人工临床gold。

尚未建立人工gold、训练校准器或锁定自动接受阈值；`confidence=null`，证据特征score不等于概率，`auto_accept_enabled=false`。本轮没有产出真实人群精度/召回、80%自动化或临床可用性结果。

下一步应在完整原文上独立标注小规模node+edge图，明确复合计划拆分、同次判断共指及同文书事件时间；再分别测规范化、候选边召回、共指和关系错误。开发校准与开发外锁定验证分开，不能用当前模型输出作为gold。ProblemThread、正式episode边界、历史证据可见性与医生Acceptable Mode Set继续独立制定。
