# HEWV v0.4：开发与数据处理不变量

这些不变量约束执行行为，四个临床阶段不是不变量。代码验证见 `tests/test_episode_extract.py`，临床覆盖与隐含计划仍需来源审阅。

| 编号 | 不变量 | 可核对结果 |
|---|---|---|
| HEWV-I01 | 本院 entry 与外院既往事件分开 | 后来记录的外院日期不新增提前的来源实例 |
| HEWV-I02 | 真正首诊与观测起点分开 | entry_basis 显式，不能因最早影像存在就声称首次visit |
| HEWV-I03 | 原文不可按医学意义改写或截取 | 纳入的文书全文 hash 与源正文相同；不出现span裁剪 |
| HEWV-I04 | 只按整份记录决定开放 | included/excluded/unresolved均为whole；未知版本不提供安全前缀 |
| HEWV-I05 | create_time 不决定临床可见性 | 扰动该字段不改变checkpoint、context或问题输入；审计原字段可变化 |
| HEWV-I06 | 事件发生不等于结果可见 | 检验采样、影像检查及病理取材不能静默替代报告/本院接收 |
| HEWV-I07 | 时间精度不被伪造 | 粗精度同日其他记录不自动开放；晚出的结果不能仅因同日进入 |
| HEWV-I08 | 已有医生建议不通过删句隐去 | 独立决策边界较晚且有更早建议候选时不生成有效messages；复核完整保留 |
| HEWV-I09 | 四问独立、允许共享或缺失节点 | 不传前问回答；不强制3/4一致；缺锚点不填造 |
| HEWV-I10 | 病例结局与分析标签隔离 | 改动state/结局字段不改变episode与输入；timeline仍仅供审阅 |
| HEWV-I11 | 不按重要性、文书标题或标本类型筛事实 | 全部已可见检验；既往术后全文/手术病理可纳入 |
| HEWV-I12 | 患者来源与输出留在本地 | 默认零模型调用，真实配置与输出仅进入忽略目录 |
