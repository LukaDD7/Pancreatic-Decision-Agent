# HEWV v0.4：可复用的 Episode 定义

## 操作性定义

一个 episode 至少包含：

| 元素 | 定义 | 不能替代它的东西 |
|---|---|---|
| 患者关联 | 同一患者的受审计来源集合 | 文件行号、影像号、病理号单独充当跨表患者键 |
| 本院范围 | 机构/来源系统边界及来源身份 | 正文出现某医院名称就自动判断整份来源归属 |
| 临床问题与情境 | 本次需要处理的病变，首次诊治/再分期/复发等 | 每次住院机械划为新病程，或同一患者终生仅一个episode |
| entry | 本院首次就诊，或最早可观测本院记录，明确依据 | 患者在外院的首次检查日期、住院建档时间 |
| 目标决策 | 哪一项建议/动作正在评价，及其来源 | 只用最后实际手术行为定义所有前置问题 |
| 任务模式 | 未见目标建议的独立选择，或已有建议下的复核 | 两种任务混合报告一个准确率 |
| checkpoint | 来源记录/报告轮次、前/后关系、时间依据与精度 | 仅给任意日期、研究者推测的钟点或阶段标签 |
| coverage | 首诊、外院接收、完整版本、报告签发等是否覆盖 | 将“没提供”解释成“阴性”“未做”或“当时不存在” |

初版每个输入患者包由 review 指定一个目标 episode；支持分别提供 review 重跑不同情境，但未实现全队列自动拆出所有 episode。上下文可包含此前已可见的相关来源，当前适配器保留所提供患者包内全部既往记录，不默认30天回看或同住院号截断。来源包是否涵盖医生真实可访问的全部资料须单独确认。

## 起点判定顺序

1. 盘点本院门诊、急诊、住院记录及影像/检验来源和覆盖期。
2. 若有可信本院首次就诊记录及原生临床就诊时间，经审阅指定 `REVIEWED_FIRST_HOSPITAL_ENCOUNTER`。软件验证字段与来源绑定，首次性仍是审阅结论。
3. 若缺首诊而只有最早报告/文书，指定 `FIRST_OBSERVED_HOSPITAL_RECORD`。它是观测覆盖起点，不认证真正首次 visit；影像事件可早于报告返回。
4. 不从后来的病史抽取旧日期回建 entry。本院首诊全文若已包含外院信息，则在该本院文书可见时完整呈现。
5. 病程起点与第一个提问 checkpoint 分开保存：就诊开始可能早于首份报告返回。当前提取器不生成缺失的检查前问诊资料。

## 四阶段与节点选择

四阶段用于确定问什么。节点用于确定给什么。一个检查可能同时提供诊断、分期与可切除性信息；不人为将一份报告分成阶段专属事实。所有问题都读取各自截点前累计完整资料。

节点可由首诊文书、完整报告、检验结果更新、取材结果等来源触发；review 必须固定选取理由，不依据实际中止切除结局倒选有利节点。缺某检查则不生成模拟结果；缺可靠阶段截点则该问未定位。允许相同证据回答不同问题，统计上按同患者相关测量处理。

## 独立治疗选择的边界

优先盘点**最早可定位的一般治疗建议**，再区分具体术式选择。只在晚出的《术前讨论》或根治术计划前截断，未必代表医生此前未建议手术。

如完整原文已包含既往手术建议：选择更早的整篇文书之前作为独立决策边界，或明确变更为复核任务。不能将计划句删掉后把其余信息当作天然存在的未决策状态。若需要文书内“先看诊断、尚未写计划”的真实过程，必须有原生增量/版本日志，不能由当前完整文书推造。

## 覆盖不足的处理

不知道首次 visit、签发时间或某篇版本，不等于整个患者不可研究。保留来源，明确可观测范围，可以先做有限资料的流程试验；正式声明“医生彼时真实可见信息”前，需要补足相应来源证据。不得通过自动摘要、回述片段前置或人工挑选有利事实填补覆盖缺口。
