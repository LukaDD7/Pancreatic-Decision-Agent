# 动态手术路径检索 v0.1

目的：寻找“先处理、先治疗或先澄清问题，再评估是否/何时切除”的病历记录，并核对是否属于当次路径安排。减黄及患者条件改善作为研究问题的一部分，不要求其必须属于证据缺口。

## 方法先于结果

`rules.json` 在本轮运行前定义五类检索及指南理由：D01 减黄/条件改善；D02 其他患者条件优化；D03 先治疗再评估；D04 治疗反应与手术安排；D05 补证据的比较情境。完整正则在该文件，不从结果报告中反推隐藏词表。

从全部固定 P0 检索，不用 P1/QC 或旧 P2 的“当前意见”标记过滤。沿用冻结的源读取模块，只取其解码、文书类型、来源和时间字段，不运行其候选链、标签分类或24/48h压缩。按原文一至两句连续片段检索，不能跨换行的段落拼接；各线索需在手术/切除锚词前后220字符内。该距离是开发检索参数，不是临床规则。

`retrieval.py` 保留完整原文片段及所有关键词坐标，避免只截局部词窗而丢掉否定/历史语境。若单句和覆盖它的双句均命中同类，保留较短者；只做词法去重，不压缩临床决策。类别可重叠。历史、未来、疑问、其他操作线索只作复核提示，不删患者或命中。

## 抽样与复核

每类抽4名不同患者：有明确历史措辞2名、没有这些措辞2名；不足则从剩余患者补足，固定种子20261021。先按患者抽，再从该患者相应条目随机取一条，避免记录特别多的人主导抽样。同一患者可进入不同类别。原先4个开发病例所属患者仅从“新样本抽样”排除，仍在检索总体中。

抽样后的源文书、两套时钟、文书类型及该患者全部范围内上下文另存。分析者复核“当前安排/旧意见/未来计划/其他操作/无法确定”，不认证临床可接受动作，不将抽样结果称为独立临床准确率。后续定向查看须与预定义抽样分开记录检索目的和选择依据。

本轮默认读取全部交付历史，不自动限定研究期；相应计数是检索覆盖，不是正式P2人数。患者—就诊键只是源索引；正文时间与系统时间都保留，不将任一套默认为临床发生/信息可见时间，不产生episode。

## 运行

在独立版本库根目录、Python3.12与pyarrow环境运行：

```bash
python -m unittest discover -s scripts/cohort_construction/p2_dynamic_pathway_probe/tests -v
python -m scripts.cohort_construction.p2_dynamic_pathway_probe.run --repo "$PWD"
```

输入是冻结P0全体患者与源行数登记、265份临床缓存及清单、原4例开发注释，以及已登记的本地NCCN v4.2026 PDF。PDF原件和患者原文不进入Git。代码逐缓存验SHA-256，逐患者核对原始源行数，再核验引文及关键词偏移。

私有输出：`local_artifacts/p2_dynamic_pathway_probe_v0.1_20261021/`。

- `hits.jsonl`：全部命中；`matched_notes.jsonl`：相应完整源文书；
- `development_sample.json`：固定抽样和分层信息；
- `sample_patient_context.jsonl`：抽样患者的全部范围内文书，用于查历史和相邻记录；
- `run_manifest.json`：输入/指南/规则/代码/抽样哈希；
- `aggregate.json`：可公开的计数，不含标识与临床原文。

`docs/p2-dynamic-pathway-probe-v0.1-20261021.json`只复制聚合结果。代码以“搜索候选”为职责，不提供自动临床分类器。宽召回导致的模板、术后叙述、其他操作等误命中必须在报告与复核记录中说明；零命中也不等于没有决策。

## 观察结果后的第二阶段（明确与预定义阶段分开）

初始20条抽样暴露出泛化的“后/恢复”等算子、风险模板和历史叙述噪声。`relation_rules.json`及`prioritize.py`随后开发，优先明确关系句式；所有30,409条原始命中仍保留。关系提示不等于确认存在独立的临床决策。其第二次抽样为每类4名不同患者、固定种子20261022，共20条，可能跨类别涉及同一患者；与初始分层抽样不同，不能当验证集。

之后为查找明确的条件性减黄安排，用`targeted.py`保存定向查询及其排序规则，取前12名不同患者；这是有意选择的开发样本。`review_context.py`为三组选择涉及的全部患者重新读取范围内原文，核对源计数并保存来源；它还为知情同意、其他操作对象、诊断小结等提供局部待核提示。此阶段不修改原有两个抽样文件或把任何患者排出P0/P2。

```bash
python -m scripts.cohort_construction.p2_dynamic_pathway_probe.prioritize --repo "$PWD"
python -m scripts.cohort_construction.p2_dynamic_pathway_probe.targeted --repo "$PWD"
python -m scripts.cohort_construction.p2_dynamic_pathway_probe.review_context --repo "$PWD"
```

最终五例由分析者在上述抽样/定向队列中选择，包含两个减黄安排、营养等待、治疗后身体条件不适合手术、治疗后再提出切除机会。具体选择ID、解释、源文书、原文偏移及相邻记录保存在私有`five_case_review.json`，选择理由不是随机抽样。`development_review_ledger.json`记录本轮查看范围与边界。原文卡按来源文书分别呈现，不是盲评包。

稳定问题编号：DYN-001术后/腹膜后误作时间关系；DYN-002风险模板误作当前条件；DYN-003试验标题误作疗效评价；DYN-004既往史相邻语句误连；DYN-005其他操作与同意材料；DYN-006“首先考虑+新辅助治疗后”诊断语句误作未来顺序。前四项加入关系优先级反例及必要对照；后两项加入局部待核提示测试，**没有声称完成全量操作对象或时间角色自动判别**。测试目录共26项合成测试，临床语义准确性仍未独立验证。
