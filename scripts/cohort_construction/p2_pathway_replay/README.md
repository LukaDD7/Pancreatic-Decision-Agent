# P2 两原则的来源检索与阶段回放 v0.2

根治路径关联、决策相关证据演化两条原则不改。新增可复用的来源登记、原始时钟、阶段分离、逐来源审计和输入编译。候选回合由显式语义审阅提出，不能把此模块称为已泛化验证的自动临床决策识别服务。

- `core.py`：导入文书、原始影像文本、原始检验单元格、病理及隔离记录；不读取NAT/随访结局、Clinical Reference、图或提议。时间保留原始含义和精度，不用创建时间冒充可见时间。检验按报告时间；影像按检查时间作回顾性代理，不能认证报告定稿或医生实际阅读。
- `prepare_scale10.py`：保留原固定种子、患者和原始容器hash，建立新来源目录与审阅材料。住院起点只用于当前检验检索上下文，不定义episode；历史影像另作语义范围复核。
- `retest_scale10.py`：本次同一AI审阅者的显式候选回合、来源区间及归组。每个候选点有一份输入，所有来源有纳入/暂缓/排除理由。没有按报告或文书数量造点，没有医生gold。
- `validate_scale10.py`：迁移基线45项检查所保护的性质，并增加CTA补回、CTA不能进入此前请求、晚MRI不前移、当前依据不误删、当前答案副本不进入输入、真实既往计划保留等整合检查。机械通过不代表独立语义或临床验证。

## 复现

在项目根目录运行：

```bash
python -m unittest discover -s scripts/cohort_construction/p2_pathway_replay/tests -v
python -m scripts.cohort_construction.p2_pathway_replay.prepare_scale10
python -m scripts.cohort_construction.p2_pathway_replay.retest_scale10
python -m scripts.cohort_construction.p2_pathway_replay.validate_scale10
python -m scripts.cohort_construction.p2_pathway_replay.report_scale10
```

新结果写入`private/p2_pathway_checkpoint_scale10_v0.2_20261024`。基线v0.1及A/B/C、手册、P1文件只读。原始source/hash/逐字跨度不改变。以后另一个样本须另定输出与语义审阅输入，不能复用这10例的人工source ID表作为泛化规则。

## 稳定问题编号与回归覆盖

| 编号 | 问题/失败风险 | 必要正反例 |
|---|---|---|
| P2SRC-001 | 仅投影documents_all导致CTA整类来源未登记；测试只在已登记源内通过 | 影像来源零文书仍导入；28日CTA进28日后续state，不能进27日请求；异常肌钙蛋白与心超也保留 |
| P2SRC-002 | 创建时间混同内容完成/可见；报告/采样混同；同日无序前移 | 原始时钟分开；同日日期不补午夜；采样早而报告晚不得前移；10例中晚MRI后续可用 |
| P2SRC-003 | 事后记载整体丢弃或实际选择/下游泄漏 | 两种术中模板保留阳性受侵，遮当前判断和操作；无模板进入语义复核而非自动排除 |
| P2SRC-004 | 新检验或重复安排自动成为点；过度要求因果词 | 无新证据/无本轮判断均不加；有经语义复核的新正常结果和当前条件判断可作候选；未来证据不能支持当前候选 |
| P2SRC-005 | 当前答案在别处重复；不计独立点的既往计划被丢弃 | 同次答案复制触发拒绝；真实历史计划保留；SCALE-05取消判断前11月8日计划保留 |
| P2SRC-006 | 按字段/截尾误删依据或原文改写 | “手术指征”中的MRI保留；SMA受侵原文保留；坐标/hash/原始限定词一致 |
| P2SRC-007 | 计划视同完成，未知/隔离结果视同无记录 | 报告时钟筛选；隔离源逐条REVIEW并保留原隔离原因，不排患者，不宣称未做 |
| P2SRC-008 | 跨患者、结局标签、版本择真或含糊引用 | 来源患者校验、字段白名单；不同原文版本并存；含糊quote需显式跨度；28旧点按原文对齐 |

隔离原检验124行的已观察原因是`INVALID_SPECIMEN_REPORT_ORDER`，本模块保留REVIEW，不修P1解析或认定临床资料差。所有时间比较使用同一交付资料的本地时钟；不声称时区和版本可见性已认证。

语义操作变化必须单列：这次8个新增项是“原先待排禁忌/条件性计划之后，已有新相关资料且文书记载当前条件评估与具体安排”的候选回合。它们既涉及新增来源，也涉及候选保留标准的一致化，不能把8项都说成已证实的算法漏检或准确率提升。
